Мучаетесь, что каждую неделю нужно сделать пару картинок и для каждой ставить отдельный инструмент и запоминать свои параметры? Здесь — одна установка, и все сценарии работы с изображениями можно смело переложить на Claude.

## Старт за 60 секунд

Главная идея: **рисование диаграмм / карточек / QR-кодов / формул — локальные движки, и распознавание изображений (OCR) тоже по умолчанию работает в процессе — ничего не вызывает AI и не требует сети, всё работает сразу после установки**. Только AI-реалистичные изображения / видео требуют бесплатного API Key — поэтому «первую картинку» и «первое распознавание» вы получаете ещё до регистрации.

### 30 секунд | Подключение одной строкой (без Key)

```bash
# Установка одной строкой (без Key, 30 секунд)
claude mcp add media-gen-mcp npx media-gen-mcp-server

# Перезапустите Claude Code → введите /mcp → увидите media-gen-mcp ✓ Connected — готово
```

### 30 секунд | Первая картинка сразу, без Key

Просто скажите Claude одну фразу:

```
Сделай тёмную техно-карточку для шеринга, заголовок: «Швейцарский нож для изображений в Claude Code»
```

→ Векторное изображение автоматически сохраняется в `output/`, можно сразу открывать и использовать. **Вы ещё не зарегистрировали ни одного API Key, а результат уже у вас.**

Вот эти запросы тоже сработают мгновенно — без Key и без сети:

- «Сделай QR-код на github.com»
- «Отрендери E=mc² как HD-формулу»
- «Нарисуй архитектурную диаграмму: клиент → шлюз → сервис заказов + сервис платежей → БД, тёмный техно-стиль»
- «Распознай цифры на этой картинке с капчей» (OCR, по умолчанию в процессе, ничего ставить не нужно)
- «Извлеки английский текст из этого скриншота»

### Хотите AI-реалистичные изображения / видео? Добавьте бесплатный API Key (опционально)

```bash
# ① Получите бесплатный API Key (рекомендуется Agnes, провайдер по умолчанию)
#    https://platform.agnes-ai.com/ → регистрация → API Keys → копируйте sk-xxx
#    (у Zhipu cogview-3-flash / cogvideox-flash тоже навсегда бесплатно — можно выбрать одного или обоих)

# ② Запишите в ~/.media-gen-mcp/config.json (можно указать только одного провайдера)
{
  "providers": {
    "agnes": { "apiKey": "sk-ваш-agnes-key" }
  }
}

# ③ Вернитесь в Claude Code и скажите: «Нарисуй киберпанк-рыжего кота, реализм»
#    → AI-реалистичное изображение сохранится. Видео аналогично: «Сгенерируй 5 секунд видео с закатом на море»
```

> Не хотите использовать npx? Подойдёт и глобальная установка: сначала `npm i -g media-gen-mcp-server`, затем `claude mcp add media-gen-mcp -s user "$(which media-gen-mcp-server)"`.

## Полный набор возможностей

> Просто скажите Claude, что хотите сделать, — он сам подберёт подходящий способ. Ниже возможности сгруппированы по «что вы хотите сделать»; вам не обязательно знать, как это называется внутри.

### Создать изображение (с нуля)

**Реалистичная фотография или иллюстрация**
> Вы: «Нарисуй киберпанк-рыжего кота, неоновое свечение, реализм»
> Получите: реалистичное изображение в `output/` (также поддерживаются иллюстрации / концепт-арт продуктов / наброски логотипов / научно-фантастические сцены)

**Превратить фразу или картинку в короткое видео**
> Вы: «Сгенерируй 5 секунд видео с закатом на море»
> Получите: MP4-видео (3–18 секунд; длинные видео генерируются в фоне, по завершении приходит уведомление)

**Скачайте иконку или брендовый логотип**
> Вы: «Дай мне логотип GitHub, 128 пикселей»
> Получите: векторный логотип из библиотеки 200 000+ иконок, готовый к использованию (GitHub / Twitter / Material / Lucide / Font Awesome и др.)

### Понять изображение (превратить картинку в данные · новое в 0.11.0)

**Извлечь текст из скриншота**
> Вы: «Прочитай цифры с этой капчи»
> Получите: чистый текст (капчи / номера счетов / отсканированные документы / истории переписки — всё извлекается)

**Превратить изображение таблицы в HTML / Markdown**
> Вы: «Распознай таблицу в этом скриншоте счёта-фактуры»
> Получите: Markdown-таблицу, готовую к вставке (счета / отчёты / сканы больше не нужно перепечатывать вручную)

**Обратное восстановление данных из диаграммы**
> Вы: «Считай данные из этой столбчатой диаграммы»
> Получите: структурированные данные CSV / JSON (годится для столбчатых / линейных / круговых диаграмм)

**Пусть расскажет об изображении простым языком**
> Вы: «Сколько людей на этой картинке? Что они делают?»
> Получите: ответ естественным языком (вопросы по изображению / рукописный текст / формулы / понимание сложных сцен)

### Чётко изобразить идею (без Key, работает сразу после установки)

**Структурные диаграммы**
> Вы: «Нарисуй архитектурную диаграмму: клиент → API-шлюз → сервис заказов + сервис платежей → БД»
> Получите: векторную архитектурную диаграмму (также поддерживаются блок-схемы / диаграммы последовательности / диаграммы классов / ER-диаграммы / интеллект-карты)

**Превратить данные в графики**
> Вы: «Построй столбчатую диаграмму по этим данным о продажах»
> Получите: HD-диаграмму данных (столбчатые / линейные / круговые / площадные / точечные — подойдёт любой набор чисел или CSV)

### Карточки / постеры / QR-коды (чтобы красиво выложить)

**Сделать карточку для шеринга / OG-изображение / карточку с цитатой / обложку / постер**
> Вы: «Сделай тёмную градиентную карточку для шеринга, заголовок „Июльские новинки 🚀"»
> Получите: аккуратно свёрстанную карточку (заголовок, подзаголовок, градиент, свечение, цветные emoji, встроенный логотип — всё автоматически; китайский и японские иероглифы не превращаются в «кракозябры»)

**Сгенерировать QR-код**
> Вы: «Сделай QR-код на github.com»
> Получите: векторный QR-код (подойдёт URL или текст; чёткий даже при печати постера)

**Отрендерить математическую формулу в HD**
> Вы: «Отрендери E=mc² как HD-формулу»
> Получите: векторную формулу (поддерживаются LaTeX, сложные дроби, химические уравнения)

### Крутые эффекты / техно-графика (одинаковый ввод всегда даёт одинаковый вывод)

**Рендеринг SVG в HD PNG**
> Вы: «Нарисуй техно-фон со свечением, звёздным полем и глубиной резкости»
> Получите: крутой PNG; автоматически выбирается лучший способ рендера, чтобы сохранить точность без потерь

**Превратить HTML / CSS-анимацию в видео**
> Вы: «Сделай 3-секундную анимацию интро продукта, градиент + частицы»
> Получите: видео MP4 / GIF / WebM (интро продуктов / брендовые анимации / демо эффектов, покадровый рендер, одинаковый ввод всегда даёт одинаковый вывод)

> **Подсказка**: создание изображений / распознавание идут через онлайн AI; диаграммы / карточки / QR-коды / анимации — локальные движки — **работают сразу после установки, векторное HD-качество, одинаковый ввод всегда даёт одинаковое изображение**.

## Подробно о конфигурации

> В двух словах: **структурные возможности (диаграммы / графики / карточки / QR-коды / формулы) работают из коробки без настройки; для AI-генерации нужна одна строка с API Key; распознавание по умолчанию не требует настройки — самохостинг нужен только для SOTA-качества на китайском / таблиц / диаграмм**. То, чем вы хотите пользоваться, и определяет, что настраивать — всё сразу настраивать не обязательно.

### Настройка по принципу «что я хочу сделать»

| Что вы хотите сделать | Что нужно настроить | Что заработает сразу |
|---|---|---|
| Рисовать архитектурные диаграммы / графики данных / карточки / QR-коды / формулы | **Ничего настраивать не нужно** | Локальный движок, работает сразу после установки |
| AI-реалистичные изображения / AI-видео (текст-в-изображение, текст-в-видео) | Один бесплатный API Key (Agnes или Zhipu, на выбор) | Онлайн-генерация, сохранение в `output/` |
| OCR-распознавание текста (английский / капчи / цифры / простые документы) | **Ничего настраивать не нужно** | По умолчанию работает лёгкий движок в процессе, сразу после установки |
| Китайский OCR / таблицы в счетах / считывание данных с диаграмм / вопросы по изображению / рукописный текст / формулы | Самохостинг движка понимания (PaddleX или vLLM, см. требования к ресурсам ниже) | После запуска самохостинг-сервиса впишите одну строку baseUrl |

### I. Настройка генерации (AI-изображения / видео)

**Провайдер по умолчанию: Agnes** (бесплатный уровень действует бессрочно, текст-в-изображение + текст-в-видео полностью открыты). Zhipu — запасной вариант (нативно оптимизирован под китайский).

**Достаточно настроить одного провайдера** (ниже полный `config.json`, можно указать только одного):

```json
{
  "providers": {
    "agnes": { "apiKey": "sk-ваш-agnes-key" },
    "zhipu": { "apiKey": "ваш-zhipu-key" }
  },
  "defaultProvider": "agnes",
  "outDir": "/absolute/path/to/output"
}
```

**Как получить бесплатный API Key**:

- **Agnes** (рекомендуется, по умолчанию): https://platform.agnes-ai.com/ → регистрация → API Keys → копируйте `sk-xxx`
- **Zhipu**: https://open.bigmodel.cn/ → регистрация → API Keys (бесплатные модели: `cogview-3-flash` / `cogvideox-flash`, навсегда бесплатно)

**Настройка обоих провайдеров повышает надёжность**: если один временно «упадёт» (rate limit / колебания сервиса), второй автоматически подхватит — вы этого даже не заметите, никакого двойного списания средств.

**Расположение файла конфигурации**: `~/.media-gen-mcp/config.json` (macOS / Linux) или `%USERPROFILE%\.media-gen-mcp\config.json` (Windows).

> Если этого файла нет — **ничего не падает**: структурные возможности и OCR по умолчанию продолжат работать, просто AI-генерация будет недоступна.

### II. Настройка распознавания (изображения / OCR / таблицы / графики / визуальное понимание)

Возможности распознавания делятся **на три уровня** — выбирайте по необходимости; первый уровень доступен сразу.

#### Уровень 1: лёгкий движок по умолчанию (без настройки, работает сразу)

- **Что умеет**: OCR английского / цифр / капчей / простых документов
- **Нужно ли поднимать сервис**: **нет**, упакован в MCP-процесс в виде WASM, языковая модель подгружается автоматически при первом вызове
- **Минимальные требования к ресурсам**:
  - CPU: любой (чисто CPU, без зависимости от GPU)
  - GPU: не требуется
  - Память: ~200–500 МБ (колеблется в зависимости от размера изображения)
  - Диск: ~30–50 МБ (WASM-движок + языковые пакеты)
  - Размер модели: включён в указанный объём диска (языковой пакет для английского, несколько МБ)
- **Скорость**: ~3–5 секунд на одно изображение
- **Кому подойдёт**: 90% лёгких сценариев OCR, зарубежные документы, распознавание капчей

> Большинству пользователей этого уровня достаточно, следующие два — опциональное усиление.

#### Уровень 2: PaddleX / PP-StructureV3 (SOTA на китайском + распознавание таблиц)

- **Что умеет**: китайский OCR (заметно точнее дефолтного движка), анализ вёрстки, **счета / отчёты / сканы → таблицы HTML/Markdown**, считывание данных с диаграмм
- **Нужно ли поднимать сервис**: **да**, самохостинг PaddleX REST-сервиса, MCP обращается к нему через `baseUrl`
- **Минимальные требования к ресурсам** (по замерам):

  | Режим | Минимум | Рекомендуется | Примечание |
  |---|---|---|---|
  | GPU-режим | RTX 3060 12 ГБ VRAM | RTX 3060 12 ГБ / Tesla T4 | Загрузка модели ~2.4 ГБ, при обработке сложных PDF пиковое ~6 ГБ |
  | CPU-режим | 4 ядра CPU + 8 ГБ ОЗУ | 8 ядер + 16 ГБ ОЗУ | Запустится (годится для лёгких документов), но на пакетной обработке / сложных PDF медленнее в 3–5 раз |
  | Диск | ~3 ГБ | ~5 ГБ | paddlepaddle + paddlex + веса моделей |
  | Размер модели | ~100–300 МБ (один pipeline) | — | Несколько pipeline складываются |

- **Требования к CUDA**: Compute Capability ≥ 7.0 (V100 / T4 / RTX 20/30/40 серии; 50-я серия пока поддерживается не полностью); для GPU-ускорения нужны CUDA 11.8 + cuDNN 8.9 + TensorRT 8.6
- **Как установить**:

  ```bash
  pip install paddlex paddlepaddle          # GPU-версия: paddlepaddle-gpu
  paddlex --serve --pipeline PP-StructureV3.yaml --port 8080
  ```

  Затем добавьте в `config.json` одну строку:

  ```json
  {
    "providers": {
      "paddle": { "baseUrl": "http://127.0.0.1:8080" }
    }
  }
  ```

#### Уровень 3: vLLM + Qwen2.5-VL (универсальная визуальная VLM)

- **Что умеет**: вопросы по изображению, распознавание рукописного текста, распознавание формул, описание сложных сцен естественным языком — задачи «понимания», с которыми не справляется PaddleX
- **Нужно ли поднимать сервис**: **да**, собственный vLLM-сервис вывода
- **Минимальные требования к ресурсам** (по замерам):

  | Режим | Минимум | Рекомендуется | Примечание |
  |---|---|---|---|
  | GPU 7B полная точность (FP16) | 16 ГБ VRAM | **24 ГБ VRAM** (RTX 3090 / 4090 / A5000) | Веса модели ~15–16 ГБ + KV cache, vLLM по умолчанию занимает 90% видеопамяти |
  | GPU 7B квантованная (INT8/AWQ) | 10–12 ГБ VRAM | 16 ГБ VRAM | Квантованная версия помещается в RTX 4080 / 4060 Ti 16 ГБ |
  | GPU лёгкая 3B | 6–8 ГБ VRAM | GTX 1660 / 3060 6–8 ГБ | FP16 ~6–8 ГБ, INT4 ~3–4 ГБ — «золотая середина» для индивидуальных разработчиков |
  | CPU-режим | Не рекомендуется | — | Запустится, но в 5–10 раз медленнее; для продакшена берите GPU |
  | ОЗУ | 16 ГБ | 16–32 ГБ | — |
  | Диск | ~14 ГБ (веса 7B) | — | 3B ~6 ГБ |
  | Требования к CUDA | Compute Capability ≥ 7.0 | — | От Tesla T4 (7.5) и выше: V100 / A100 / RTX 30/40 серии |

- **Как установить**:
  ```bash
  pip install vllm
  vllm serve Qwen/Qwen2.5-VL-7B-Instruct --port 8000
  # Появится «Uvicorn running on http://0.0.0.0:8000» — сервис готов
  ```
  Дополнительные параметры (выбор GPU / квантованные версии / лимит параллелизма) см. в [официальной документации vLLM](https://docs.vllm.ai). Затем добавьте в `config.json`:

  ```json
  {
    "providers": {
      "vlm": { "baseUrl": "http://127.0.0.1:8000" }
    }
  }
  ```

|---|---|---|---|---|---|---|
| **По умолчанию** (tesseract) | Нет | Ноль (чистый CPU WASM) | Средне | ❌ | ❌ | Apache 2.0 |

### III. Автоматический fallback (настроил и забыл)

- **Сторона генерации**: Agnes ↔ Zhipu, при сбое одного автоматически переключается на другого (мягкое переключение после неудач в течение 60 секунд — вам не нужно перезапускать MCP или менять конфигурацию)
- **Сторона распознавания**: лёгкий движок по умолчанию (фолбэк внутри процесса) → PaddleX → vLLM, автоматическая деградация по возможностям
- **Единственное исключение**: при опросе статуса видео **переключение не выполняется** (чтобы не получить чужой ошибочный результат)
- Что нужно сделать вам: настроить API Key для двух провайдеров генерации + опционально поднять один уровень сервиса распознавания — остальное Claude возьмёт на себя

> Ваша машина не тянет PaddleX или vLLM? **Продолжайте использовать лёгкий движок по умолчанию** — MCP не упадёт из-за отсутствия локального сервиса, просто будут недоступны SOTA на китайском / таблицы / вопросы по изображению, всё остальное продолжит работать как обычно.

## Частые вопросы

**В: Можно ли пользоваться, ничего не устанавливая?**
О: Да. После установки MCP у вас сразу есть рисование диаграмм / карточек / QR-кодов / формул / графиков данных + английский / капчи OCR — всё работает локально, без сети.

**В: Китайский распознаётся с «кракозябрами»?**
О: Лёгкий движок по умолчанию годится для английского / цифр / простых документов, но точность на китайском средняя. Для SOTA на китайском поднимите свой PaddleX (GPU 12 ГБ или CPU 4 ядра 8 ГБ), подробности см. в разделе [Подробно о конфигурации](#подробно-о-конфигурации).

**В: Сколько ждать AI-видео?**
О: 5-секундное видео — примерно 1–3 минуты, 18-секундное — возможно 5–10 минут. Генерация идёт асинхронно в фоне, по завершении вы получаете уведомление; то, что оценивается ≤60 секунд, дождётся синхронно.

**В: Мой RTX 3060 потянет распознавание таблиц?**
О: Да. Минимум для GPU-режима PaddleX — 12 ГБ VRAM (RTX 3060 12 ГБ как раз подходит), для CPU-режима хватит 4 ядер + 8 ГБ ОЗУ (медленнее в 3–5 раз). Подробнее см. в [Подробно о конфигурации](#подробно-о-конфигурации).

**В: Китайский / emoji / градиенты рендерятся нормально?**
О: Да. В карточках через встроенные китайские шрифты + движок вёрстки полностью автоматически поддерживаются китайский, японские иероглифы, цветные emoji, градиентные заголовки и эффекты свечения — никакой дополнительной настройки шрифтов не требуется.

**В: Поддерживается ли Mermaid?**
О: Нет (требуется браузер). Используйте взамен D2 или Graphviz — возможности те же, но стабильнее, и векторный вывод.

**В: Попадаю на rate limit (429)?**
О: На бесплатном уровне есть лимит запросов в минуту. После настройки двух провайдеров (Agnes + Zhipu) переключение происходит автоматически, вы почти ничего не замечаете.

**В: Какие ограничения по количеству кадров в видео?**
О: Уменьшаются с ростом разрешения — 1080p ≤ 241 кадр (~10 секунд), 720p — до 441 кадра (~18 секунд). Можете попросить Claude проверить актуальные ограничения.

**В: npx не подключается / медленно запускается?**
О: Подойдёт и глобальная установка: сначала `npm i -g media-gen-mcp-server`, затем `claude mcp add media-gen-mcp -s user "$(which media-gen-mcp-server)"`.

**В: Можно ли использовать чувствительные слова / оружие / военную тематику?**
О: Слова про реальное оружие активируют фильтр контента. Замените их на научно-фантастические термины (например, «боевой экзоскелет будущего», «меха») — это обойдёт фильтр, эффект тот же.

## Кому это подходит

- **Активные пользователи Claude Code** — те, кто несколько раз в неделю занимается задачами с изображениями и не хочет для каждой ставить отдельный MCP и запоминать свой набор параметров.
- **Разработчики, пишущие техническую документацию / блоги** — кому регулярно нужны архитектурные диаграммы, диаграммы последовательности, ER-схемы, графики данных, формулы, и кто не хочет выходить из рабочего процесса.
- **Индивидуальные разработчики / самостоятельные продукты** — те, кто следит за расходами (всё бесплатно) и предсказуемостью (одинаковый ввод → одинаковый вывод), и кто не хочет поднимать отдельный бэкенд только ради задач с изображениями.
- **Аналитики данных / финансы / юристы** — сценарий в обе стороны: превратить данные в графики, а из скриншотов / счетов обратно извлечь точки данных.
- **Маркетинг / контент-мейкеры / авторы публичных аккаунтов** — карточки для шеринга / OG-изображения / постеры / QR-коды: китайский + цветные emoji + градиенты работают из коробки.

> **Не очень подходит**: пользователям без Claude Code; командам, которым нужно одно конкретное умение и у которых уже выстроен пайплайн; сценариям, требующим платных коммерческих моделей / обучения и тонкой настройки / OCR видео в реальном времени (это выходит за рамки бесплатного MCP).
