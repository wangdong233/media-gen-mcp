## ✨ Особенности

- 🆓 **Полностью бесплатно** — AI-генерация изображений и видео через Agnes AI + бесплатные модели Zhipu; структурный рендеринг полностью локальный, нулевая стоимость
- 🧠 **Нулевой порог обучения** — просто говорите обычным языком, Claude сам выбирает инструмент, генерирует код и создаёт изображение
- 📐 **Детерминированный вывод** — структурные диаграммы/графики/формулы/карточки: одинаковый ввод всегда даёт одинаковый вывод, содержимое под контролем
- 🇨🇳 **Дружелюбен к китайскому языку** — карточки автоматически рендерят китайский (встроенные шрифты); модели Zhipu изначально заточены под китайский
- 🔌 **Ничего не нужно доустанавливать** — D2 / Graphviz / Vega / MathJax всё встроено, не нужно ставить d2/dot/matplotlib в системе
- 🎨 **Крутой рендеринг** — свечение feGaussianBlur / градиенты / глубина резкости, автоматически через высокоточный рендер Chrome
- 🌐 Документация на 8 языках · MIT · Node ≥18

## 🚀 Быстрый старт

### ① Получите бесплатный Key

Зарегистрируйтесь у любого из провайдеров ниже (или у обоих) и получите бесплатный API Key:

| Провайдер | Бесплатно | Регистрация |
|---|---|---|
| **Agnes AI** (по умолчанию) | Текст-в-изображение + текст-в-видео полностью бесплатно | https://platform.agnes-ai.com/ → Регистрация → API Keys |
| **Zhipu BigModel** (опционально, 4K / китайский) | cogview-3-flash изображения + cogvideox-flash видео навсегда бесплатно | https://bigmodel.cn/usercenter/proj-mgmt/apikeys → Верификация личности → Создать Key |

> Подробные инструкции со скриншотами: [Руководство по Agnes](doc/Agnes%20开通指引.md) · [Руководство по Zhipu](doc/Zhipu%20开通指引.md)

### ② Конфигурация

Создайте `~/.media-gen-mcp/config.json` и впишите ваш Key:

```json
{
  "providers": {
    "agnes": { "apiKey": "sk-ваш-agnes-key" },
    "zhipu": { "apiKey": "ваш-zhipu-key" }
  }
}
```

Можно настроить только agnes (удалите строку zhipu). Если не указать `models`, будут использоваться встроенные модели по умолчанию.

### ③ Подключение к Claude Code

```bash
claude mcp add media-gen-mcp npx media-gen-mcp-server
```

Команда подключения **без Key** (Key уже в конфиге выше). Если в `/mcp` видно `media-gen-mcp ✓ Connected` — всё готово.

### ④ Скажите одну фразу

В Claude Code просто скажите «нарисуй архитектурную диаграмму» или «сгенерируй реалистичное изображение рыжего кота» — готово.

> **Нужны только структурные диаграммы/графики/карточки/QR-коды?** Key не нужен — просто установите (шаг ③) и пользуйтесь.

| | По умолч. | Изображения (бесплатно) | Видео (бесплатно) | Особенности |
|---|:---:|---|---|---|
| **agnes** | ✅ | agnes-image-2.1-flash | agnes-video-v2.0 | Полностью бесплатно, реалистичное качество, нативные звук и изображение |

## 🛠️ Подробно о возможностях

### 🤖 AI-генерация (бесплатные модели · онлайн)

Используйте бесплатные модели Agnes AI или Zhipu:
- **Текст-в-изображение / изображение-в-изображение** — реализм, иллюстрации, концепт-арт
- **Текст-в-видео / изображение-в-видео / анимация ключевых кадров** — умный асинхронный режим (длинные видео генерируются в фоне, уведомление по завершении)
- Указание провайдера/модели: «нарисуй через **Zhipu cogview-4**» / «сгенерируй видео через **agnes**»

### 📐 Структурный рендеринг (локально · детерминированно · без Key)

Следующие возможности **не вызывают AI, вывод детерминирован** (векторный SVG в высоком качестве):

| Возможность | Движок (все встроены) | Описание |
|---|---|---|
| **Структурные диаграммы** | D2 + Graphviz | Архитектура/процессы/последовательность/классы/ER/интеллект-карты, автоматическая раскладка |
| **Графики данных** | Vega-Lite | Столбчатые/линейные/круговые/площадные/точечные, Claude генерирует из данных автоматически |
| **Математические формулы** | MathJax | LaTeX → SVG, глифы встроены |
| **Карточки для шеринга** | Satori | OG/постеры/карточки с цитатами (китайский + градиенты + emoji + свечение автоматически) |
| **QR-коды** | qrcode | URL/текст → SVG/PNG |
| **Векторные иконки** | Iconify | 200 000+ иконок (`icon: "mdi:home"`) |
| **Крутой SVG** | Chrome / resvg | Рукописный SVG (свечение/фильтры/глубина) → высокоточный рендер через Chrome |

<details>
<summary>📖 Что умеют карточки?</summary>

- 5 шаблонов: og (левая иерархия) / quote (цитата, кавычки обрамляют слева и справа) / minimal (минимализм) / hero (крупный шрифт + блики) / panel (стеклянная панель)
- Градиентный текст заголовка + свечение + размытые блики для глубины
- Встроенный logo / круглый avatar
- Автоматический китайский (Noto Sans SC офлайн) + автоматические цветные emoji (кеш на диске, работает без сети)
- Настраиваемые размеры (по умолчанию 1200×630, стандарт OG)
</details>

<details>
<summary>📖 Что такое крутой SVG-рендер?</summary>

Движок D2 не поддерживает SVG-фильтры (свечение feGaussianBlur), поэтому когда нужен эффект «крутого тёмного техно-вида, свечения, глубины резкости»:
1. Claude пишет SVG вручную (с фильтрами вроде feGaussianBlur)
2. вызывается инструмент `render_svg`
3. инструмент сам выбирает бэкенд: если есть `<filter>` и в системе доступен Chrome → Chrome (100% точность фильтров); иначе → resvg (92%, лёгкий)
</details>

<details>
<summary>📖 Об офлайне (какие инструменты требуют сеть?)</summary>

- **Полностью офлайн**: generate_diagram / generate_chart / generate_formula / generate_qrcode
- **Кеш после первого онлайн-запроса, далее офлайн**: generate_card (латиница по умолчанию — шрифт Inter — впервые берётся из CDN и кешируется в `~/.media-gen-mcp/fonts/`; CJK-шрифт Noto Sans SC уже встроен офлайн; emoji twemoji кешируется на диске и работает без сети)
- **Требуют сеть**: generate_icon (Iconify API для получения иконки); render_svg при наличии фильтров (нужен Chrome)
- **Всегда онлайн**: AI-инструменты генерации (generate_image / create_video)
</details>

## ❓ FAQ

**Видео медленное?** 3–18 с, примерно 1–3 минуты. Пропустите `wait` для асинхронного режима (>60 с возвращает handle, уведомление по завершении).
**Сколько кадров?** Передайте `durationSeconds` — выберется автоматически (5/10/18 с). Agnes допускает только 81/121/161/241/441.
**Попадаете на 429?** Встроена последовательная отправка с паузой 62 с + автоматическое обучение реальным лимитам.
**Нужен ли Key для структурных инструментов?** Нет. Установите — и сразу рисуйте диаграммы/графики/карточки/QR-коды.
**Китайский/emoji/градиенты в карточках?** Всё автоматически: встроенный CJK-шрифт + twemoji emoji (кеш на диске) + CSS-градиентный фон.
**Крутой SVG?** Claude пишет SVG вручную (со свечением feGaussianBlur) → `render_svg` → 100% точность фильтров в Chrome.
**Поддерживается ли Mermaid?** Нет (нужен браузер). Используйте D2 вместо него (покрывает процессы/последовательность/классы/ER/интеллект-карты).
**Config не читается?** Он должен находиться в `~/.media-gen-mcp/config.json`.
**`npx` не подключается?** Запасной вариант — глобальная установка:
```bash
npm i -g media-gen-mcp-server
claude mcp remove media-gen-mcp
claude mcp add media-gen-mcp -s user "$(which media-gen-mcp-server)"
```
