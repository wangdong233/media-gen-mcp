## 已确定的关键决策(probe + 审查钉死)

1. **架构 = template-store**(B1 probe 确认 D2 SVG `.text-bold` 等通用 class 多 SVG 同 DOM 冲突 → 同时只一个 SVG 在 DOM,innerHTML 切换)
2. **drill 拦截 = D2 原生 link**(B2 probe 确认 `node: { link: "url" }` 产出 `<a href xlink:href>` → JS preventDefault 拦截 `drill:*` 链接做导航,零 DSL 扩展)
3. **manifest schema = 6 字段**:id/label/diagram 必填 + diagramType/children/notes 选填(C6 裁决)
4. **MVP = Path A**(显式 manifest,N 段独立 D2;Path B defer)
5. **工具名 = generate_nested_diagram**(C9:viewer-stack.ts,不用 nested)
6. **尺寸 = NESTED_SIZE_CAP 1MB**(soft N≤6 / hard N≤50)
7. **salt = `media-gen-mcp-nested-${node.id}`**(id 校验 `^[a-z0-9-]+$` 保合法)
8. **label escapeHtml**(C1 信任边界,viewer 侧强制)
9. **byte-identical 红线**:generate_interactive_diagram 的 golden 不破;本工具是独立 entry
