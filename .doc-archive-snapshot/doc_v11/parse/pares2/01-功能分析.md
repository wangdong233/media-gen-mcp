  message: string;

### 9.1 本阶段新发现 open_point

14. **PRD §1.1/§2.4/§4.2.2 pattern 1 的 Vega-Lite 触发样本需订正**(本阶段实测发现) — 待实施者在 Step 10 写冒烟测试时按本节修正。

        type:foo → THROWS: Invalid field type "undefined".
        type undefined (no field type) → OK
        type null → THROWS: Invalid field type "undefined".
