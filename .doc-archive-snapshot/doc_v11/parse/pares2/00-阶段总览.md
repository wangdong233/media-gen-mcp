## 1. 本阶段做了什么

### 1.1 解决的 LLM 试错盲区(用户视角)

media-gen-mcp 的 4 个本地确定性引擎(D2 / Graphviz / Vega-Lite / resvg)抛的 stderr 是给**人**看的,不是给 **LLM(Claude)** 看的。Claude 收到这些裸 stderr 后常需 3–5 轮试错才修对一条输入:

| 引擎 | 裸 stderr 形态(旧版) | LLM 难读根因 | 归一化后(新版) |
|---|---|---|---|
| **D2** | `[{"range":"index,0:25:25-0:28:28","errmsg":"index:1:26: expected \"stroke-width\" to be a number between 0 and 15"}]` | JSON 数组 dump + 0-indexed range vs 1-indexed errmsg 不一致 | `[d2] line 1: D2 属性 "stroke-width" 仅接受整数,合法范围 0–15。 \| offending: x: { style.stroke-width: 1.5 } \| 修复:把 stroke-width 改为 0–15 之间的整数(如 stroke-width:2 ✅ / stroke-width:1.5 ❌,小数非法)。` |
| **Graphviz** | `graphviz engine produced no SVG` | viz-js v3 语法错**不抛错**,返回 `{status:"failure", errors:[...]}`;旧 catch 是死代码,真实错被丢弃 | `[graphviz] line 1: DOT 语法错(第 1 行,意外 token "}"). \| offending: digraph G { A -> } \| 修复:检查 ① 大括号 {} 配对;② 每条语句以 ; 或换行结束;③ -> 引用的节点须先出现;④ 属性用 [key=val] 赋值。` |
| **Vega-Lite** | `Invalid field type "undefined"` | 不告诉 LLM 合法集合是什么、哪个 channel 出错 | `[vega-lite] encoding.<channel>.type="<缩写或空>" 的 type 值 "undefined" 不合法(通常是拼错或用了缩写,被静默转 undefined)。 \| 修复:type 合法值仅有 4 个:quantitative / nominal / ordinal / temporal。不要用缩写(如 quant/quantitativ),必须写全。` |
| **resvg** | `SVG data parsing failed cause the document does not have a root node` | 不区分"缺 xmlns / 非数字坐标 / 未知元素"3 类失败;字体失败串不连续(`default font-family '' not found`)被旧 rx 漏匹配 | `[resvg] resvg 解析 SVG 失败。真实原因常是下列之一:① 根标签缺 xmlns 属性;② 某些属性值非数字;③ 含 resvg 不支持的元素。 \| offending: <svg><rect width="50" \| 修复:三步排查:① 根标签写 <svg xmlns="..." ...>;② 检查所有 rect/path 的 x/y/width/height/r 是纯数字;③ 若用了 feGaussianBlur/CSS filter,改用 render_svg 的 backend:"chrome"。` |

### 4.4 反崩溃契约三层守卫(F8 正面观察)

`normalizeEngineError` 主入口实现了三层反崩溃守卫,任何意外输入形态都不穿透到顶层 catch:

1. **make 函数 try/catch**:pattern 表的 `make` 是模式表自写代码,任何意外输入(如 resvg pattern 1 历史 bug:对象 ctx.input 调 `.slice`)在 make 内抛 TypeError 时,catch 回退到 rawMsg 兜底
2. **兜底分支未命中 pattern**:返回 `[engine] rawMsg + 未识别标记`,绝不抛
3. **typeof check(F1 修复)**:兜底分支对 object ctx.input 用 JSON.stringify,不再输出 `[object Object]`

7 道闸门里的 anti-crash case 群(空字符串 rawMsg / 未识别错误形态 / object ctx.input / TypeError regex 永不出现)逐条锁死。
