### 4.1 F11 · sentinel 碰撞导致静默数据损坏(medium,数据逻辑)

- **位置**:`src/interactive-html/fill-template.ts:39-41`(SVG 替换无 /g 标志)+ `src/interactive-html/index.ts:84-125`(buildInteractiveHtml 入口无 sentinel 校验)
- **复现 probe**:`unit/fillTemplate [KNOWN-BUG-PROBE F11]` + `/tmp/probe_f11_f14.mjs`
- **现象**(实测):
  ```
  escapeHtml('__MGM_SVG_SLOT__') = "__MGM_SVG_SLOT__"   ← 下划线不转义
  titleCount: 1                                          ← SVG 整段跑进 <title>

  ```
- **用户视角后果**:title 内嵌 sentinel 字面 → viewer 里看到字面字符串而非图(静默数据损坏,无错误信号)

### 4.2 F12 · darkTheme 空白字符串边界(medium,数据逻辑)

- **位置**:`src/interactive-html/index.ts:115`(`if (req.darkTheme != null) assertDualPalette`)+ L122(`hasDarkLightDualPalette: req.darkTheme != null`)

### 4.3 F13 · handler catch 把契约 assert 错按 D2 归一化(medium,数据逻辑)
