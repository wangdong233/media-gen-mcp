#### F11 [medium] · src/interactive-html/fill-template.ts:39-41 sentinel 碰撞导致静默数据损坏

- **现象**:fill-template.ts:39-41:
  ```ts

    .replace(new RegExp(escapeRegex(TITLE_SENTINEL), "g"), () => titleEscaped)
    .replace(new RegExp(escapeRegex(SVG_SENTINEL)), () => opts.svg);
  ```
  **碰撞路径**(实测确认):
  1. 用户传 `title='__MGM_SVG_SLOT__'`(或任何含该字面字符串的 title);

  5. stage `<div>` 仍保留字面 `'__MGM_SVG_SLOT__'` 文本 → 用户在 viewer 里看到的是字面字符串而非图。

- **影响**:静默数据损坏 —— 最危险的一类 bug(无错误信号 + 产物不可用)。4 条 medium 中**唯一可能导致静默数据损坏**的 finding。
- **触发条件**:用户构造含 sentinel 字面的 title。可能性低(用户不会主动这么做),但 LLM 生成 title 时若把 sentinel 字面拼入(如某个文档系统把变量名当 title),会命中。

    ```ts
      throw new Error("title must not contain sentinel strings ...");
    }
    ```
  - 方案 B(顺序换):先把 SVG 填进模板,再把 title 填进剩余的 TITLE sentinel(因 SVG 内部不含 TITLE sentinel 字面,逻辑顺序换一下更安全;但仍要防 SVG 内含 TITLE sentinel)。
