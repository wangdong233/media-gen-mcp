# media-gen-mcp 排期与里程碑

> 目标:把 media-gen-mcp 从"AI 文生图/视频"演进为"一个 server 覆盖所有生图"——AI 生图 + 结构化生图(确定性、本地)。
> 节奏:P0 → P1 → P2,每阶段 6 步(分析 → 实现 → 审查 → 测试 → 文档 → 自检),全部通过方可进入下一阶段。

---

## 总览

| 阶段 | 主题 | 工具 | 渲染方式 | 状态 |
|---|---|---|---|---|
| **P0** | 结构化生图(一) | generate_diagram / generate_qrcode / generate_chart | 本地确定性(D2 / qrcode / Vega-Lite) | ✅ 已交付(2026-07-14) |
| **P1** | 结构化生图(二) | generate_formula / generate_icon | 本地确定性(MathJax)/ 联网(API+缓存) | ✅ 已交付(2026-07-14) |
| **P2** | 卡片生图 | generate_card(含 OG/social card) | 本地确定性(Satori + resvg)/ 字体 CDN+缓存 | ✅ 已交付(2026-07-14) |

> 设计原则(贯穿三阶段):
> 1. **同一心智模型**——对用户都是"生成一张图";AI 与本地确定性是内部路由,用户无感。
> 2. **同一落盘流程**——`writeLocalRender()` helper 复用(文件名清洗 + PNG 断言 + 去重)。
> 3. **本地确定性优先**——能不联网就不联网;AI 仅用于无法确定性表达的写实/创意内容。
> 4. **引擎与 Provider 分离**——`DiagramEngine` 不污染 `MediaProvider` 契约。

## P1 —— 结构化生图(二)[✅ 已交付]

补齐"用户想要、但 P0 未覆盖"的两类确定性生图。详见 [phase/p1/P1_交付分析.md](phase/p1/P1_交付分析.md)。

- **generate_formula** —— LaTeX → SVG(MathJax-full liteAdaptor)。字形路径内嵌,无字体依赖;PNG 走 Resvg fitTo 处理 ex 单位。
  - 关键陷阱:`new SVG({ font: "tex" })` 会把字符串当字体对象 → 必须用 `new SVG()`(默认 tex)。
- **generate_icon** —— Iconify 公共 API 按需取 + LRU 缓存(256)。**唯一联网工具**(不打包 70MB 全集以保 npx 轻量);prefix/name 分别编码保留 `:`。

关键修复:generate_icon schema `name` 撞名(图标名 vs 输出文件名)→ 文件名由图标名派生(`mdi:home`→`mdi-home`)。

**完成日**:2026-07-14。构建通过,模块级 8 用例 + MCP 集成(9 工具 / 2 调用)验证通过。

## P2 —— 卡片生图 [✅ 已交付]

`generate_card` —— Satori(VNode→SVG)+ resvg(SVG→PNG)。3 模板(og/quote/minimal),默认 1200×630 PNG。详见 [phase/p2/P2_交付分析.md](phase/p2/P2_交付分析.md)。

- **字体**:默认 Inter(Latin)从 jsDelivr @fontsource 首取 + 磁盘缓存(`~/.media-gen-mcp/fonts/`);`fontPath` 指向本地字体即完全离线。**中文卡片需 fontPath 指向 CJK 字体**(Inter 仅 Latin)。
- **关键修正**:og 模板初版用 `position:absolute` 放页脚触发 Satori "多子节点必须 display:flex" 约束 → 改纯 flexbox 列布局。
- **类型**:Node `Buffer.buffer`(ArrayBuffer|SharedArrayBuffer)显式窄化;satori weight 字面量联合。

**完成日**:2026-07-14。构建通过,模块级 9 用例 + 视觉验证(OG 卡片布局正确、无乱码)+ MCP 集成(10 工具)验证通过。

**P0+P1+P2 全部完成 —— 10 个工具,所有生图归一个 MCP。**
