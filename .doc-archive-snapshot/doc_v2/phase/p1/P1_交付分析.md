## 1. 背景与选型

P0 把 diagram/qr/chart 接入后,"结构化生图"还缺两个高频品类:用户常说的"渲染这个公式"和"给我一个图标"。P1 补齐。

### 1.1 generate_formula —— 数学公式

| 候选 | 产出 | 结论 |
|---|---|---|
| **MathJax-full**(liteAdaptor + TeX + SVG jax) | SVG,字形路径内嵌,无字体依赖 | ✅ 选用 |
| KaTeX | HTML+CSS 字符串,无干净独立 SVG | ✗ 链路不稳 |
| Temml | MathML,Resvg 不渲染 MathML | ✗ |

**关键陷阱(耗费多轮排查)**:`new SVG({ font: "tex" })` 会让构造函数把 `this.options.font`(字符串 `"tex"`)直接赋给 `this.font`,导致 `this.font.params.x_height` 报 `Cannot read properties of undefined`。**根因**:`OutputJax` 构造函数 `_this.font = _this.options.font || new defaultFont(...)` —— 传了 `font` 选项就把字符串当字体对象。**修复**:用 `new SVG()`(默认即 tex 字体,不传 font 选项)。许多流传的示例写 `{ font: "tex" }`,在 mathjax-full@3.2.1 下是错的。

### 1.2 generate_icon —— 矢量图标

| 候选 | 体积 | 结论 |
|---|---|---|
| `@iconify/json` 全集打包 | ~70MB | ✗ 会让 `npx media-gen-mcp-server` 安装变重,破坏轻量接入故事 |
| **Iconify 公共 API + 内存缓存** | 0(按需) | ✅ 选用 |

**取舍**:图标是本 server **唯一需要联网**的工具(diagram/qr/chart/formula 全本地)。用 `https://api.iconify.design/{prefix}:{name}.svg` 按需取单个图标,LRU 缓存(256 项)避免重复请求。离线抛清晰错误。这是体积与离线性之间最务实的平衡——文档明确标注网络依赖。

## 3. 关键实现细节

### 3.1 formula.ts

- **引擎 lazy singleton**:`getEngine()` 只初始化一次(adaptor + TeX(AllPackages) + SVG jax)。`RegisterHTMLHandler` 必须在 `mathjax.document` 之前(否则 "Can't find handler for document")。
- **PNG 通路**:MathJax SVG 的 width/height 是 `ex` 单位,Resvg 无法解析。用 `Resvg(svg, { fitTo: { mode: "width", value } })` 按 viewBox 等比缩放到目标像素宽 + 白底。
- **颜色**:MathJax SVG 字形用 `currentColor`,在根 `<svg>` 上注入 `color="..."` 即可改色。
- **错误**:LaTeX 编译失败 → `try/catch` 包成 "LaTeX compile failed: ..."。注意 MathJax 对多数"语法不完整"输入是**宽容渲染**(不抛错),仅真正无法处理时才抛——这是 MathJax 设计,非 bug。

### 3.2 icon.ts

- **URL 构造**:`prefix` 与 `name` 分别 `encodeURIComponent`,中间保留字面量 `:`(Iconify 路径约定)。早期 `encodeURIComponent(name)` 会把 `:` 编成 `%3A`,虽然 Iconify 容忍,但严格代理/CDN 可能失败。
- **缓存**:Map 保持插入序实现简易 LRU,超 256 项删最旧;命中时 delete+set 重置为新近。
- **错误分级**:无冒号名 → "icon name must be prefix:name";404 → "icon not found ... Browse valid names";网络异常 → "icon tool needs network"。

## 7. 已知边界 / 后续

- **icon 联网**:唯一联网工具。若需完全离线,未来可选打包常用图标集(`@iconify-json/mdi` 等 scoped 包)子集 + API 兜底长尾。
- **MathJax 体积**:mathjax-full 较大(~40MB unpacked),首次 `require` 略慢;靠 lazy singleton 仅首次调用加载。npx 安装体积增加,可接受(确定性公式的唯一可靠方案)。
- **formula 颜色**:依赖 MathJax 字形用 currentColor(多数成立);极少数显式 fill 的字符不受 `color` 影响,属已知局限。
