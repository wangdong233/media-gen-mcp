## 1. 背景与选型

P0/P1 覆盖了结构图、图表、公式、图标、二维码。还缺一类高频需求:博客/文章的分享卡片(OG image)、引言卡。P2 用 Satori + resvg 补齐。

### 1.1 渲染引擎

| 候选 | 产出 | 结论 |
|---|---|---|
| **Satori**(Vercel) | JSX/VNode → SVG(flexbox 子集),成熟,OG 场景标配 | ✅ 选用 |
| node-canvas | 需 cairo 原生依赖,重 | ✗ |
| 手写 SVG | 过低层,排版难 | ✗ |

PNG 复用既有 resvg(SVG→PNG,diagram/chart/formula 已验证)。

### 1.2 字体策略(本阶段核心难点)

Satori **必须**传入字体数据(ArrayBuffer),无系统字体自动加载。矛盾:打包 CJK 字体体积巨大(~10MB+),破坏 npx 轻量;不打包则默认空字体无法渲染。

| 方案 | 取舍 | 结论 |
|---|---|---|
| 打包字体子集 | 体积大,授权/归属麻烦 | ✗ |
| 系统字体路径 | 不跨平台(macOS/Linux/Windows/CI 不一致) | ✗ |
| **CDN 按需取 + 磁盘缓存 + fontPath 离线兜底** | 默认 Inter(Latin)首次从 jsDelivr @fontsource 取,缓存到 `~/.media-gen-mcp/fonts/`;CJK/离线传 `fontPath` | ✅ 选用 |

与 Iconify 同构(联网取 + 缓存),`fontPath` 提供完全离线路径。**中文卡片**:默认 Inter 仅 Latin,需 `fontPath` 指向 CJK 字体——文档显著标注。

## 3. 关键实现细节

### 3.1 字体加载(`loadFont`)

- **三级查找**:`fontPath`(本地文件)→ 内存缓存(`family@weight`)→ 磁盘缓存(`~/.media-gen-mcp/fonts/{key}.woff`)→ CDN 取(jsDelivr @fontsource)。
- **类型窄化**:Node `Buffer.buffer` 类型是 `ArrayBuffer | SharedArrayBuffer`,`toArrayBuffer()` 用 `as ArrayBuffer` 显式窄化(satori 要求 ArrayBuffer)。
- **weight 字面量**:satori 的 `FontOptions.weight` 是 `100|200|...|900` 联合,定义 `FontWeight` 类型,加载 400/700 两个权重(覆盖正文与标题加粗)。
- **缓存写失败不阻塞**:CDN 取到的字体写盘失败只忽略,不阻断渲染。

### 3.2 模板布局(纯 flexbox)

- **og**:列布局 `[内容行(flex:1) + 页脚]`,内容行 = 竖强调条 + 文本列(标题/副标题/正文)。
- **quote**:居中大字引言 + 引号 + 页脚。
- **minimal**:居中标题 + 副标题。

**Satori 约束**:每个含多个子节点的 `<div>` 必须显式 `display:flex`。初版 og 用 `position:absolute` 放页脚 → 触发该约束报错;改为纯 flexbox 列布局(内容行 flex:1 撑开 + 页脚沉底),所有容器显式 flex。

### 3.3 安全/注入

title/subtitle/body/footer 是**程序构造的 VNode**(非 HTML 字符串),Satori 按 React 元素语义渲染 → 无 HTML 注入/XSS 面。fontPath 是用户本机文件(用户主动传),无提权风险。

## 8. 已知边界 / 后续

- **CJK 卡片**:默认 Inter 仅 Latin,中文需 `fontPath` 指向 CJK 字体。后续可考虑内置一个紧凑 CJK 子集或 CJK 字体 CDN(`@fontsource/noto-sans-sc` 等)。
- **卡片渐变背景**:P2 v1 仅纯色 + 强调条;Satori 支持 `linear-gradient`,后续可加 `gradient` 选项。
- **Emoji**:Satori 不内建彩色 emoji 渲染(需 emoji 字体);当前模板不含 emoji。需要时可配合 icon 工具或加 emoji 字体。
- **字体 CDN 依赖**:jsDelivr 不可达时默认字体失败;`fontPath` 是离线兜底,文档已标注。
