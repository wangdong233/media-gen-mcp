> **迭代**:pares5 · **阶段**:M1 · **日期**:2026-07-19

## 一、tesseract.js API(v5+,已调研确认)

[tesseract.js docs](https://github.com/naptha/tesseract.js/blob/master/docs/api.md) · [examples](https://github.com/naptha/tesseract.js/blob/master/docs/examples.md) · [worker-api 6.0](https://tessl.io/registry/tessl/npm-tesseract-js/6.0.0/files/docs/worker-api.md)

```js
const { createWorker } = require('tesseract.js');
const worker = await createWorker('eng');          // v5:async,自动加载 lang(无 load/loadLanguage/initialize)
await worker.setParameters({
  tessedit_char_whitelist: '0123456789',            // digitOnly → 白名单
  tessedit_pageseg_mode: '7',                       // PSM 7=单行
});
const { data: { text, confidence } } = await worker.recognize(imageUriOrBuffer);
await worker.terminate();
```

**关键**:`createWorker(lang)` 单参即加载语言(v5 简化);`recognize` 接受 URL/Buffer/data URI(与我 VisionRequest.image URI 同约定);`{data:{text,confidence,...}}`。

## 二、语义级 hints → tesseract 参数翻译(采纳审查 finding-1,引擎词零泄漏)

接口层只暴露语义级 what,tesseract.ts 内部翻译为引擎 how:

### BCP-47 → tesseract lang 文件名
| BCP-47(接口) | tesseract lang(内部) |
|---|---|
| `zh-Hans` | `chi_sim` |
| `zh-Hant` | `chi_tra` |
| `en` | `eng` |
| `ja` | `jpn` |
| `ko` | `kor` |
| 其他 | 透传主子标签(去 `-` 后小写) |

### segmentation → PSM(tessedit_pageseg_mode)
| segmentation(接口) | PSM(内部) | 含义 |
|---|---|---|
| `auto`(默认) | `3` | 全自动版面 |
| `single-line` | `7` | 单行文本(验证码/数字表盘) |
| `single-char` | `10` | 单字符 |
| `sparse-text` | `11` | 稀疏文字 |

### digitOnly → tessedit_char_whitelist
`digitOnly: true` → `tessedit_char_whitelist: '0123456789'`(各引擎语义契约,tesseract 用 whitelist 实现)。

## 三、TesseractProvider 设计(src/providers/tesseract.ts)

`implements MediaProviderBase, VisionProvider`:

| 方法 | 实现 |
|---|---|
| `name` | `"tesseract"` |
| `listModels()` | `[]`(tesseract 无模型概念,按 lang 走) |
| `listVisionModels()` | `[]` |
| `visionTasks()` | `["extract-text"]`(只做 OCR;表格/图表/描述不声明) |
| `recognize(req)` | 主逻辑(见下) |
| `visionConstraints()` | `{ languages: [...支持的 BCP-47], maxImageBytes: 10MB }` |
| `capabilities()` | `{ image:{...全 false}, video:{...全 false} }`(无生成能力) |
| `health()` | `{ configured: true, cooldown: false }`(进程内 WASM 恒可用) |
| `tier()` | `1`(fallback 兜底,最低优先) |
| `notifyUnavailable()` | no-op(进程内不会"不可用") |

### recognize(req) 主逻辑
1. 断言 `req.task === "extract-text"`(其他 task 抛清晰错——tesseract 只声明 extract-text)
2. 取 hints:`const h = (req.hints as ExtractTextHints) ?? {}`
3. 翻译:langs = `(h.languages ?? ["en"]).map(bcp47ToTesseract)`;psm = `segToPsm(h.segmentation ?? "auto")`
4. 获取/复用 worker(单例,见下);若 lang 变了 reinit
5. `worker.setParameters({ tessedit_pageseg_mode: psm, ...(h.digitOnly ? {tessedit_char_whitelist:'0123456789'} : {}) })`
6. `const { data } = await worker.recognize(req.image)`
7. 构造 blocks(每行一个 TextBlock,bbox+confidence) + text(全文)
8. 返回 `{ task:"extract-text", text, blocks, raw: data }`

### WASM worker 单例生命周期(0.7.0 教训)
- **单例懒加载**:模块级 `let worker: Worker | null`,首次 recognize 时 `createWorker`
- **lang 复用**:记录当前 lang,同 lang 跨调用复用(不 reinit);lang 变则 terminate + 重建
- **不主动 terminate**:MCP server 长驻(StdioServerTransport 保活),worker 常驻无害(对称 0.7.0 d2 worker 在 server 无害的判定)
- **独立脚本/测试**:若 hang,测试末尾 `worker.terminate()` 或导出 `__terminateForTest()`(参考 d2 的 unref+active refcount 模式);tesseract.js worker 是 worker_threads,默认会 pin 事件循环

## 四、extract_text 工具(schema + handler)

### schema(extract_text)
| 参数 | 类型 | 说明 |
|---|---|---|
| `image` | string(必填) | http(s)/data URI;本地文件先 read 为 data URI |
| `languages` | string[]? | BCP-47,默认 `["en"]`;中文用 `["zh-Hans","en"]` |
| `digitOnly` | bool? | 验证码/纯数字→白名单 |
| `segmentation` | enum? | auto/single-line/single-char/sparse-text,默认 auto |
| `outputFormat` | enum? | text/json,默认 text(json 含 blocks+bbox) |
| `provider` | string? | 默认 config.defaultVisionProvider |
| `name`/`outDir` | string? | 落盘 .txt(可选) |

### handler(index.ts switch 加 case)
```
case "extract_text": {
  image = requireString(a.image); if (!isImageUri(image)) return err(URI 提示);
  resolved = resolveProvider(optString(a.provider), optString(a.model), "vision");
  p = asVisionProvider(resolved.provider);
  if (!p.visionTasks().includes("extract-text")) return err("provider X 不支持 extract-text");
  hints = { languages, digitOnly, segmentation };
  result = await p.recognize({ image, task:"extract-text", hints });
  // fallback 链(M1 仅 tesseract,M2 加 paddle 后生效):recognize 抛 isFallbackWorthy → getFallbackProvider vision
  落盘 .txt(可选,outputFormat=text)
  return ok({ text, blocks?, provider_used: p.name, warnings? });
}
```

**fallback 链**(M0 已铺 getFallbackProvider vision 分支):recognize 抛 isFallbackWorthy 错 → `getFallbackProvider(p.name, "vision", {task:"extract-text"})` → M1 仅 tesseract,无第二 vision provider → 返回 undefined → 抛原错 + 配置指引。M2 加 paddle 后自动 fallback tesseract↔paddle。

## 七、风险

1. **tesseract.js WASM 首次下载 lang 数据**(chi_sim ~ 10MB):首次识别中文慢。缓解:文档说明;langPath 可配本地。
2. **中文精度弱**(tesseract 公认短板):M1 诚实声明,M2 paddle 接入后中文走 paddle(PP-OCRv6 SOTA)。
3. **worker pin 事件循环**:测试脚本可能 hang。缓解:导出 terminateForTest 或 unref。

## 八、M1 审查结果 + 修复(5-agent workflow,25 findings)

**2 🔴 CRITICAL + 多 🟡**,关键真实 bug(mock 掩盖的)全修:

| finding | 修复 |
|---|---|
| 🔴 blocks 提取死代码(tesseract.js@7 Page 无 `lines`,在 `blocks[].paragraphs[].lines[]`;且默认 `blocks=false`) | `recognize(img,{},{blocks:true})` + 改提取路径 `data.blocks[].paragraphs[].lines[]` |
| 🔴 BCP47 表大小写不匹配(表 key `"zh-Hans"` vs lookup `toLowerCase`→查不到→fallback `"zh"`→tesseract 无 zh.traineddata 崩溃,100% 复现) | 表 key 全小写 |
| 🟡 setParameters 合并语义 whitelist 残留(digitOnly 切换不清→同 worker 连续调用泄漏) | 非 digitOnly 显式 `whitelist:""` |
| 🟡 zh-CN/zh-TW/zh-HK 别名→split "zh" 崩溃 | 表补 region 变体(zh-cn/zh-tw/zh-hk/zh-sg/zh-mo) |
| 🟡 getWorker 并发 TOCTOU(两 recognize 不同 lang 竞态→孤儿 worker) | workerPromise 串行化(terminate→createWorker 链式) |
| 🟡 bcp47 fallback 不安全(en-US→"en" 非 "eng") | fallback 递归查表(主子标签再查) |
| 🟡 extract_text catch 缺 fallback warning(对比 generate/create) | 加 `warnings.push(fallback 提示)` |
| 🟡 SEG_TO_PSM 裸字符串 + worker `any` | 用 tesseract.js 导出的 `PSM` enum + `Worker` 类型 |
| 🟡 visionConstraints `maxImageBytes` 零消费(handler 不校验) | 删(YAGNI;M2/M3 真要时再加 + handler 校验) |
| 🔵 schema 缺 `download` 字段(handler 读但 schema 无) | inputSchema 加 download |
| 🔵 eslint-disable 假保护(line 53 内嵌语法不生效;项目无 eslint) | 删 |

**未改(🔵 合理/低优)**:outputFormat json 0 行省略 blocks(合理);warning 硬编码 "tesseract"(M2 多 provider 时改);createWorker CDN 首次(文档说明);recognize 无超时(M2/M3 加);真实 OCR 测试(联网,留用户测试);imageConstraintsNote 对 vision 误触发(M2 优化 buildListModelsDetail)。
