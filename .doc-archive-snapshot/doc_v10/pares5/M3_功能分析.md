## 一、技术路径(vLLM OpenAI 兼容,标准协议)

与 M2 不同(paddleocr-mcp 是 MCP 协议陷阱),**vLLM 暴露的是标准 OpenAI 兼容 REST**,Node fetch 直接用,无握手/会话/SSE。

**端点**:`POST {baseUrl}/v1/chat/completions`(vLLM 默认 :8000;DashScope compatible-mode 同构,但付费 → 不进默认)
**Headers**:`Authorization: Bearer {apiKey}`(vLLM 自托管可空 key;`Content-Type: application/json`)
**请求体**(OpenAI vision 格式):
```json
{
  "model": "Qwen2.5-VL-7B-Instruct",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "image_url", "image_url": { "url": "<http 或 data:URI>" } },
      { "type": "text", "text": "<prompt 按 task 构造>" }
    ]
  }]
}
```
**响应**:`choices[0].message.content`(文本)

**部署**(用户侧,README 手册):
```bash
pip install vllm
vllm serve Qwen/Qwen2.5-VL-7B-Instruct --port 8000  # 自托管,Apache,免费
```
用户配 `providers.vlm.baseUrl = "http://127.0.0.1:8000"` + `apiKey`(vLLM 可空)。

**License**:Qwen2.5-VL **7B/32B = Apache-2.0**(免费可商用);3B Research/72B MAU 限制 → 不用。对齐纯免费立场。

## 二、VLMProvider 设计(src/providers/vlm.ts)

`implements MediaProviderBase, VisionProvider`:

| 方法 | 实现 |
|---|---|
| `name` | `"vlm"` |
| `visionTasks()` | `["describe-image", "analyze-chart"]`(VLM 强项;extract-text/table 走 tesseract/paddle) |
| `health()` | `{ configured: !!baseUrl, cooldown, lastErrorAt? }` |
| `tier()` | `8`(paddle=10 主力;vlm=8 次主力 fallback;tesseract=1 兜底) |
| `capabilities` | 全 false(纯识别) |

### recognize(req) 按 task 构造 prompt
- **describe-image**:`question` 存在→ VQA 直接问;空→ "Describe this image in detail."
- **analyze-chart**:"Extract all data points as JSON {x,y,label} from this chart."
- extract-text/table:不在 visionTasks,抛清晰错(走 tesseract/paddle)

### 复用
- `withRetry` + 错误挂 `.status/.body`(symmetric paddle/agnes)
- `uriToPaddleFile` 不用(vlm 接受 http/data URI 原样作 image_url.url,OpenAI 格式)

## 三、fallback 链(M3 补全,M2 已铺 runVisionTask)

```
extract_text:   paddle(10) → tesseract(1)       ← M2 已通
extract_table:  paddle(10) 唯一 → 挂则报错        ← M2
analyze_chart:  paddle(10) → vlm(8)              ← M3 补 fallback
describe_image: paddle(10) → vlm(8)              ← M3 补 fallback + VQA(question)
```

M2 的 `runVisionTask` 已用 `getFallbackProvider("vision", {task})`,M3 注册 vlm 后**自动生效**(vlm 的 visionTasks 含 describe/chart,被选为 fallback)。无需改 handler,只注册 vlm provider。
