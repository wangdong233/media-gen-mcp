# pares2 —— 卡片渐变背景(功能分析)

> 迭代目标:generate_card 支持渐变背景(linear/radial gradient),不再仅纯色。
> 来源:0.2.0 已知边界"卡片仅纯色 + 强调条"。父文档:[../排期与里程碑_v3](../排期与里程碑_v3.md)

---

## 1. 现状与目标

- 0.2.0:`bg` 仅接受纯色(默认 #0f172a),根 div `background: bg`;PNG 经 resvg 时也传 `background: bg` 兜底。
- 目标:`bg` 同时接受**纯色或 CSS 渐变串**(`linear-gradient(...)` / `radial-gradient(...)`),自动路由渲染。

## 2. 技术调研(已实测)

- **Satori** 支持 `backgroundImage: "linear-gradient(...)"` 与 `"radial-gradient(...)"`,将渐变烘焙为 SVG `<linearGradient>/<radialGradient>` def(实测 svg 含该 def)。
- **不**支持 shorthand `background: linear-gradient(...)` → 必须用 `backgroundImage`。
- **resvg**:渐变已在 SVG 内,resvg 原生渲染(`<linearGradient>` 支持),**无需也不可**再传纯色 `background`(传 "linear-gradient(...)" 给 resvg 会被当颜色解析报错)。
- 实测 PNG:linear(135deg, indigo→cyan)与 radial 均正确渲染,平滑无断层,文字清晰(视觉验证)。

## 3. 执行路径(改动点)

`src/card.ts`:
1. 新增 `isGradient(s)`:`/gradient\s*\(/i`。
2. 根 div style:`bg` 为渐变 → `backgroundImage: bg`(不设 `background`);纯色 → `background: bg`(原行为)。
3. resvg PNG:渐变 → 不传 `background`(渐变已在 SVG);纯色 → 保留 `background: bg` 兜底。
4. 渐变下默认文字色仍 `#f8fafc`(深底亮字);accent 强调条不变。

`src/index.ts`:`bg` schema 描述补充"支持 CSS 渐变,如 linear-gradient(135deg, #4f46e5, #06b6d4)"。

文档:README 卡片行/FAQ 示例补渐变用法。

## 4. 风险与边界

| 风险 | 处理 |
|---|---|
| 非法 gradient 串 | Satori 报错 → handler 返回错误(可接受) |
| 误把渐变串传给 resvg | 代码按 isGradient 分支,resvg 仅纯色时传 background |
| 渐变 + 浅色停点致白字不可读 | 用户自洽(提供 color 覆盖);默认深底 |
| 与 CJK 字体交互 | 无关(背景独立于字体);pares1 渐变叠加仍工作 |

## 5. 验收标准

- [ ] linear-gradient 卡片正确渲染(视觉验证渐变出现)。
- [ ] radial-gradient 卡片正确渲染。
- [ ] 纯色卡片不回归。
- [ ] 渐变 + CJK 文本叠加正确。
- [ ] resvg 不因渐变串报错。
- [ ] 单元/集成/冒烟 + 四维度审查零问题;文档更新。
