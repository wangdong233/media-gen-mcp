## pares1 —— CJK 字体内置 [✅ 已交付]

详见 [parse/pares1/CJK字体内置_分析.md](parse/pares1/CJK字体内置_分析.md)。

- **方案**:依赖 `@fontsource/noto-sans-sc`,文本含 CJK 时自动加载 `chinese-simplified` 子集(`.woff`;Satori 不支持 woff2)作回退,`fontFamily` 栈 `Inter, Noto Sans SC` 逐字形回退。
- **关键**:字体用各自 family 名(同名会互相遮蔽致 tofu);`.woff` 非 `.woff2`;离线(随包 deps)。
- **验证**:中文 og/混合/纯英文/fontPath+中文 全通过,视觉确认无 tofu;MCP 端到端通过。

## pares2 —— 卡片渐变背景 [✅ 已交付]

详见 [parse/pares2/卡片渐变背景_分析.md](parse/pares2/卡片渐变背景_分析.md)。

- **方案**:`bg` 同时接受纯色或 CSS 渐变串(`linear-gradient`/`radial-gradient`);`isGradient()` 分流:Satori 用 `backgroundImage`(渐变烘焙进 SVG)或 `background`(纯色);resvg 仅纯色时传 `background` 兜底,渐变已在 SVG 内不再传。
- **关键修复**:Satori 对 style 对象中的 `undefined` 值会 `.trim()` 报错 → 用条件展开 `...(isGrad ? {backgroundImage} : {background})`,避免 undefined 键(测试中捕获并修复)。
- **验证**:linear/radial/纯色/默认/CJK+渐变/SVG 6 用例通过,视觉确认渐变平滑无断层、强调条可见;MCP 端到端通过。

## pares3 —— emoji [✅ 已交付]

详见 [parse/pares3/emoji支持_分析.md](parse/pares3/emoji支持_分析.md)。

- **方案**:Satori `loadAdditionalAsset` 选项,`code === "emoji"` 时返回 twemoji **PNG data URI**(非 URL——resvg 不抓远程;非 SVG——SVG-in-SVG 不可靠)。Satori 自动把 emoji 作内联图嵌入文本流。
- **codepoint**:过滤 FE0F、保留 ZWJ,twemoji 文件名拼接;内存缓存。
- **验证**:og/CJK+emoji/渐变+emoji+中文/无 emoji/SVG 5 用例通过,视觉确认 🚀🎉📦✨ 彩色;中文叠加正常;MCP e2e 通过。
- **边界**:emoji 需联网取 twemoji(缓存);失败降级 tofu;72×72 源(标题字号清晰)。

## pares4 —— Graphviz/Mermaid 引擎补齐 [✅ 已交付]

详见 [parse/pares4/Graphviz_Mermaid引擎_分析.md](parse/pares4/Graphviz_Mermaid引擎_分析.md)。

- **Graphviz ✅**:`@viz-js/viz`(Graphviz WASM)新增 `GraphvizEngine`,与 D2Engine 同型(lazy singleton + 清晰错误 + resvg PNG)。render.ts 注册 d2+graphviz。
- **Mermaid ❌(经查证进程内不可行)**:三方印证(研究 agent + v2 历史 + 实测 mermaid-isomorphic@3 强依赖 playwright/Chromium)。拒污染全局的 jsdom 方案(风险波及同进程 D2/Vega/Satori)。engine 枚举保留 mermaid(可发现性),handler 给清晰错误 + 推荐用 d2/graphviz。
- **验证**:graphviz SVG/PNG(MCP e2e)、d2 不回归、mermaid 清晰错误、非法 DOT 清晰错误,全通过;无全局污染(未引入 jsdom/Chromium)。

**pares1–pares4 全部完成。0.3.0 待发布。**

generate_diagram 的 `engine` enum 含 `d2/mermaid/graphviz`,但 0.2.0 仅 d2 实现。本迭代补齐。

- **Graphviz**:候选 `@hpcc-systems/wasm`(WASM dot,进程内)或 `@viz-js/viz`(基于 viz.js emscripten)。
- **Mermaid**:进程内渲染历史上不稳(isomorphic-mermaid 模块损坏、mermaid-isomorphic 需 Chromium)。需深度调研可行性;若确不可行,如实记录并以 Graphviz + d2 覆盖,不造假。
- **风险**:高。Mermaid 可能无法纯进程内;Graphviz WASM 体积。结论以调研为准。
