## pares2 交付明细

**新增选项(跨模板,作用于标题):**
- `titleGradient`(CSS gradient → background-clip:text 渐变文字)
- `glow`(text-shadow 辉光;`true`=accent 派生,或传 text-shadow 值)
- `blob`(hero 模板:标题背后 filter:blur 光斑,默认 true)

**新增模板:**
- `hero` — 居中大字(104px)展示型,叠模糊光斑纵深。
- `panel` — 内容置于玻璃面板(border+圆角+box-shadow+半透明)内。

**覆盖的 Satori 特效**:渐变文字、text-shadow 辉光、box-shadow、border、border-radius、opacity、filter:blur、background-clip。未暴露的(transform 倾斜)按需可再加。**JS 执行/动画**仍需 HTML+Chrome(Satori 不支持)。
