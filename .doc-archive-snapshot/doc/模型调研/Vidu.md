## 二、开源情况

| 项目 | 是否开源 | 说明 |
|---|---|---|
| **Vidu 主模型**(Q1/Q2/Q3) | ❌ 闭源 | 仅通过 API/网页使用,不提供权重下载 |
| **TurboDiffusion 框架** | ✅ 开源 | 2025年12月开源。单张 RTX 5090 仅需 1.9 秒生成 5 秒视频,效率提升 100-200 倍。这是推理加速框架,非生成模型本身 |

> 结论:Vidu 的文生图/文生视频**生成模型全部闭源**,无法本地部署。TurboDiffusion 仅为加速框架(需配合其他模型使用)。

## 五、API 协议(关键:非 OpenAI 兼容)

| 项目 | 详情 |
|---|---|
| **协议类型** | ❌ **私有协议**(非 OpenAI 兼容,无 `/v1/images/generations` 端点) |
| **Base URL** | `https://api.vidu.com`(国际)/ `https://api.vidu.cn`(国内) |
| **鉴权方式** | `Authorization: Token {api_key}`(**注意是 `Token` 不是 `Bearer`**) |
| **调用模式** | **异步任务制**:POST 创建任务 → 返回 `task_id` → 轮询 `GET /ent/v2/tasks/{id}/creations` 或通过 `callback_url` 回调 |
| **端点示例** | 文生视频:`POST https://api.vidu.com/ent/v2/text2video`;图生视频:`POST /ent/v2/img2video`;参考生视频:`POST /ent/v2/reference2video`;首尾帧:`POST /ent/v2/start-end2video` |
| **API Key 管理** | 每账号最多 10 个活跃 Key |
| **官方 MCP Server** | ✅ 平台提供 "Mcp 服务"(见文档侧栏) |

### 请求示例(文生视频)
```bash
POST https://api.vidu.com/ent/v2/text2video
Content-Type: application/json
Authorization: Token {your_api_key}

{
  "model": "viduq3-turbo",
  "prompt": "一只猫在草地上奔跑",
  "duration": 5,
  "resolution": "720p",
  "aspect_ratio": "16:9",
  "audio": true,
  "callback_url": "https://your-server.com/callback"
}
```

## 七、适合 media-gen-mcp 的评估

| 维度 | 评估 |
|---|---|
| **API 协议** | 私有协议,需自定义 provider(**custom**)。异步任务制 + `Token` 鉴权,无法直接套用 OpenAI SDK |
| **集成难度** | 中等:需实现"创建任务→轮询/回调→下载视频"三段式逻辑。但官方已提供 **MCP Server**,可优先尝试直接接入 |
| **文生图** | viduq2 支持(1080p/2K/4K,$0.03-$0.05/图),价格有竞争力 |
| **文生视频** | Q3-turbo 性价比突出($0.055-$0.065/秒 720p-1080p),16 秒长视频+原生音频 |
| **免费额度** | 仅 200 积分限时活动(约 $1),**不适合生产环境免费测试**,需充值起步 |
| **区域** | 国际版(vidu.com)+ 国内版(vidu.cn)双平台,国内访问友好 |

**结论:适合 custom provider 接入**。若官方 MCP Server 可直接用,则首选 MCP 接入;否则需为 Vidu 编写私有 provider(处理 `Token` 鉴权、异步任务轮询、回调签名验证)。

## 八、需核实事项

1. 200 免费积分活动 **当前(2026-07)是否仍有效**、有效期多久(限时活动,官方未在 Quickstart 文档固定)。
