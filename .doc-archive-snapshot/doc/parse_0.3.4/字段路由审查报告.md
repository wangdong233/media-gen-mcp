# 字段路由审查报告(类似 quote bug 排查)

> 起因:0.3.2 测试发现 quote 模板忽略必填 `title`(引言放 title 时只剩装饰引号、正文丢失),0.3.3 修复。
> 本审查:全面排查"必填字段被忽略 / 字段静默丢弃 / 输出残缺却不报错"的同类问题。
> 方法:经验视觉扫描(每模板 × 字段组合,视觉确认内容)+ 代码走查(字段→模板路由矩阵)+ 其他工具必填字段核查。

---

## 1. 字段 × 模板矩阵(实测,视觉确认)

| 模板 | title(必填) | subtitle | body | footer |
|---|---|---|---|---|
| og | ✅ | ✅ | ✅ | ✅ |
| quote | ✅(0.3.3 修) | ❌(无 subtitle 概念) | ✅ | ✅ |
| minimal | ✅ | ✅ | ❌(刻意极简) | ❌(刻意极简) |
| hero | ✅ | ✅ | ❌(展示型,正文用 panel) | ✅(0.3.4 补) |
| panel | ✅ | ✅ | ✅ | ✅ |

## 2. 结论

- **无残留关键 bug**:5 模板全部正确渲染必填 `title`。quote 那种"必填字段被忽略致输出残缺"是孤例,已修。
- **一个真实缺口已补**:hero 原静默丢弃 footer(展示卡带 credit/署名很自然)→ 0.3.4 补上。
- **按设计的字段裁剪**(非 bug):minimal=只 title+subtitle(顾名思义);quote=引言(title)+正文+署名(无 subtitle 概念);hero 展示型不含正文(要正文用 panel)。**已在 schema description 标注各模板支持的字段**,避免静默丢弃的意外。

均为"单一必填输入→单一渲染",无多字段静默丢弃风险。

## 4. 修复(0.3.4)

- `layoutHero` 增加 footer(credit/署名行,副标题下方,小字 muted)。
- `generate_card` schema `template` 描述补各模板字段支持表。

## 5. 防复发

- 任何新模板:**必填字段(title)必须在 children 里**,review 卡此项。
- 模板不支持某可选字段时,优先在 schema/description 标注(已对 template 做了),避免"静默丢弃"意外。
- 经验视觉扫描(每模板全字段 + 仅 title)是抓此类 bug 的有效手段,纳入后续模板变更的自测。
