## 功能分析

### #1 免费 Provider 自动 Fallback

**目标**：generate_image/create_video 在 provider 持续不可用（5xx/超时/鉴权），自动 fallback 到另一个**免费** provider。用户不花钱。

**架构决策：Handler 层 fallback**（非 provider/router 层）：
- http.ts withRetry 已在 provider 层做 3 次重试 → fallback 是重试耗尽后的保险
- Handler 层有完整上下文（warnings/fan-out/download/async hint）→ fallback 对这些透明
- Provider 层 fallback → 循环依赖（agnes→zhipu→agnes）；Router 层 → 过早抽象（仅 2 provider）

**fallback 触发条件**（isFallbackWorthy）：
- 5xx（已被 withRetry 耗尽 3 次）→ YES
- status=0 / TypeError（网络层）→ YES
- 401/403（鉴权/欠费）→ YES
- 429（限流，已被 learnRateLimit 捕获）→ YES
- 400/404 等业务 4xx → NO（换 provider 只会更早出错）

**铁律：poll 路径（getVideo/waitVideo）绝不 fallback**（任务 ID 是 provider 私有的）。

**spec 不兼容处理**：fallback 时按目标 provider 的 imageConstraints/videoConstraints 重吸附 size/numFrames。

### #2 MediaProvider 接口扩展

**目标**：加 capabilities()/health()/tier()/notifyUnavailable() optional 方法，为 fallback 能力谈判 + 未来扩展预留。

**零破坏**：全 optional，agnes/zhipu 不实现也能编译；registry/handler 用 `p.capabilities?.()` 守卫。

```typescript
// types.ts 新增
interface ProviderCapabilities {
  image: { textToImage: boolean; imageToImage: boolean };
  video: { textToVideo: boolean; imageToVideo: boolean; keyframes: boolean };
}
interface ProviderHealth {
  configured: boolean;   // apiKey 已配置
  cooldown: boolean;     // 最近连续失败，临时熔断
  lastErrorAt?: string;  // ISO 时间
}
// MediaProvider 追加(optional):
capabilities?(): ProviderCapabilities;
health?(): ProviderHealth;
tier?(): number;
notifyUnavailable?(e: any): void;
```

### #3 图像编辑

**调研结论：Agnes/Zhipu 当前无免费图像编辑 API**
- Agnes：仅 OpenAI 兼容 /images/generations（文生图），无 /images/edits 端点确认
- Zhipu：cogview 纯文生图，无编辑端点

## 风险 + 缓解

| 风险 | 缓解 |
|---|---|
| spec 不兼容 → 400 | fallback 时按 fb.imageConstraints/videoConstraints 重吸附 size/numFrames |
| videoConstraints 不兼容 | fallback 时 nearestAllowed 到 fb.allowedNumFrames + warnings 显著说明 |
| keyframes 不支持 | capableOf gate（zhipu 不承接 keyframes fallback） |
| 异步 hint provider 错位 | 引入 activeProvider 变量，后续 hint/provider_used 都用它 |
| 429 双写 | notifyUnavailable 把 429 视为软 cooldown，health().cooldown 短时跳过 primary |
| flapping 双倍 quota | cooldown 60s 窗口，连续失败后直接跳过 primary |
| model 丢失语义偏移 | fallback 后 drop model（用对方默认）+ warnings 显著提示 |
