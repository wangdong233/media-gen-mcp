## 1. 核心设计原则

| 原则 | 含义 | 来源 |
|---|---|---|
| **所有生图归一个 MCP** | AI 生图 + 结构化生图对用户是同一心智模型,融合在一个 server | 用户产品立场(推翻独立 diagram-mcp 方案) |
| **工具定义是唯一信息源** | MCP 不依赖 Claude 训练数据;description + inputSchema 是 Claude 首次完美使用的全部依据 | 0.3.9-0.3.14 深度调研(Anthropic 文档) |
| **本地确定性优先** | 能不联网就不联网;AI 仅用于无法确定性表达的写实/创意内容 | 架构基线 |
| **引擎与 Provider 分离** | DiagramEngine 接口与 MediaProvider 并行,互不污染(厂商/连接 vs 引擎/语法) | P0 架构决策 |
| **可插拔** | provider 与渲染引擎皆可扩展,新增零改工具层 | P0 架构决策 |
| **快速生成-快速微调范式** | 交互增强走「AI 听得懂话 → 薄交互层」的混合范式,不自研编辑器;自研拖拽 5+ 人日拿 60% 价值,混合范式 0.5 人日拿 90%(10× ROI) | doc_v12 范式调研(2026-07-21) |
| **识别依赖 license 三梯队核查** | 新增识别/文档智能依赖必须过商用 license 分档:🟢 全栈 Apache/MIT 无门槛(tesseract/PaddleOCR/RapidOCR/Qwen2.5-VL 7B/32B);🟡 宽松主体+附加条款(MinerU 署名、Docling 须切 heron 模型避 CC-BY-NC);🔴 商用硬门槛(Marker GPL-3.0、DocLayout-YOLO AGPL 网络传染、Surya >$5M 授权)。纯 MIT/Apache 优先 | doc_v10 图像识别开源方案调研(2026-07-20) |
| **本地 provider 是战略线非替代品** | 云渠道 100% 依赖是战略缺口;本地 AI 走 **sidecar 模式**(Ollama/ComfyUI),进程内跑 SD 已证不实用(显存/速度不达);本地是云失败时的兜底与离线场景补充,不追求替代云端质量 | doc_v4 离线调研 + doc_v8 开源生态调研(2026-07) |

## 2. 架构契约(接口与模式)

### 2.1 接口
- `MediaProvider`:AI 模式(在线 API),子类 ImageProvider/VideoProvider。方法:generateImage/createVideo/getVideo/listModels/videoConstraints/estimateGenerationSeconds。
- `DiagramEngine`:本地确定性渲染。方法:isAvailable/listTypes/render。实现:D2Engine/GraphvizEngine。
- 两接口**平行独立**,不互相 import。

### 2.2 共享模式
- `writeLocalRender()`:diagram/qr/chart/formula/icon/card 共用。basename 清洗(BL-04 防路径遍历)+ PNG 断言(DL-02 不静默回退)+ 去重(R-CI-02)。
- `loadFont()`:三级缓存(内存→磁盘 `~/.media-gen-mcp/fonts/`→CDN),按 weight 分别缓存。
- `resolveImageSrc()`:URL/data URI 原样;本地路径→data URI(按扩展名定 mime)。读失败**抛错**(不静默)。
- `resolveD2Icons()`:D2 SVG 后处理——解析 `<image href="set:name">` 光引用 → fetch Iconify → 光栅化 PNG → 嵌 data URI;404 移除。无图标时不动(保持离线)。
- `emojiToDataUri()`:三级缓存(内存→磁盘 `~/.media-gen-mcp/emoji/`→CDN twemoji)。

### 2.3 单例与序列化
- D2 实例 lazy singleton(每实例 worker+22MB WASM,无 terminate)+ 串行队列防 sendMessage 竞态。
- MathJax 引擎 lazy singleton(adaptor + TeX + SVG jax)。
- 字体/emoji/icon 缓存:进程内 Map。

### 2.4 配置
- 主目录:`~/.media-gen-mcp/config.json`(npx/全局兼容;项目内不可用)。
- 原子写入:temp + rename。
- Provider 动态遍历:新增 provider 只加 config 段 + registry 注册 + 实现文件(config.ts 零改)。
- 默认 provider 三级回退:工具参数 > 按模态(defaultImageProvider/defaultVideoProvider) > 全局(defaultProvider)。
- Fallback **完全可配**(不内置);限流**可配 + 自学习**(429→解析→写入 rateLimits→TTL 过期降级)。

## 3. 工具描述规范(三层信息)

每个工具的 description + inputSchema 必须覆盖三层:

### 3.1 WHEN(路由层)— 让 Claude 自动选用
- **意图先行**:句首 = 动词 + 用户场景(如 "Generate architecture / flowchart / sequence diagrams")。
- **多语言触发词**:中文 + ja/es/fr/de/ru/pt 的核心名词(如 架构图/流程图 + 図/diagrama/diagramme/Diagramm/диаграмма/diagrama)。
- **反 fallback**:"BUILT IN (WASM/JS bundled), do NOT shell out to d2/dot/graphviz, do NOT use HTML+Chrome/Pillow/matplotlib, prefer this over any manual approach"。
- **不触发竞争心智模型**:卡片描述**勿**句首提 "CSS flexbox"(会激活 HTML 心智模型)。
- **与相邻工具划界**:card 描述末尾 "For illustrated/photographic subjects use generate_image"。

### 3.2 HOW(语法层)— 让 Claude 首次写对
每个 DSL 输入参数(`code`/`spec`/`tex`)必须包含**零知识速查表**:
- 语法规则(常见陷阱,如 D2 map 属性每行一个)。
- 可用选项(shapes 列表、mark 类型、encoding channels)。
- 正确示例(至少一个完整的可直接用的例子)。
- 常见错误(明确列出 "WRONG... RIGHT...")。
- 官方文档链接。

### 3.3 LIMITS(边界层)— 让 Claude 知道边界
- 引擎做不到的(JS 执行/动画/woff2/backdrop-filter/3D transform)。
- 功能组合限制(titleGradient + glow 不叠加;Satori 多子必须 flex;Vega 饼图用 theta 非 angle)。
- 网络/离线边界(icon 联网;card 默认字体 CDN+缓存,fontPath 可离线)。
- 渲染限制(Mermaid 进程内不可行,清晰报错 + 推荐 d2/graphviz)。

## 4. 技术陷阱清单(已解决,防复发)

| # | 陷阱 | 正确做法 | 来源 |
|---|---|---|---|
| 1 | MathJax `new SVG({ font: "tex" })` 把字符串当字体对象 → params.x_height 崩 | `new SVG()`(默认即 tex) | P1 |
| 2 | Satori 多子节点 div 不写 `display:"flex"` → 崩 | 每个含多子的 div 显式 flex | P2 |
| 3 | Satori style 对象含 `undefined` 值 → `.trim()` 崩 | 条件展开 `...(cond?{a}:{b})` | 0.3.2 |
| 4 | Satori CJK 同名字体互相遮蔽 → tofu | 各自 family 名 + `fontFamily: "Inter, Noto Sans SC"` 栈逐字形回退 | 0.3.0 |
| 5 | Satori 不支持 woff2 | 用 `.woff` | 0.3.0 |
| 6 | Satori emoji 用 URL → resvg 不抓远程;用 SVG data URI → SVG-in-SVG 不可靠 | `loadAdditionalAsset` 返回 **twemoji PNG data URI** | 0.3.0 |
| 7 | D2 实例每次 new → worker+22MB 泄漏 | lazy singleton | P0 |
| 8 | D2 无效输入 → worker reject → unhandled → 杀进程 | 链尾 `.catch(()=>undefined)` | 0.3.11 |
| 9 | D2 `icon:` → WASM 不嵌入 → 碎图 | `resolveD2Icons` 后处理:Iconify fetch → PNG → embed | 0.3.11 |
| 10 | D2 map 属性单行空格分隔 → 解析错 | 每行一个属性(参数描述已标注) | 0.3.13-14 |
| 11 | Vega `new View()` 不 finalize → 泄漏 | try/finally `view.finalize()` | P0 |
| 12 | Vega 饼图用 `angle` → 空图(v5 改了) | 用 `theta` + mark `"arc"` | 0.3.14 |
| 13 | glow `0 0 40px ${accent}99` 对 3 位 hex → 非法颜色崩 | `withAlpha()` 转 rgba | 0.3.7 |
| 14 | glow:"false" 字符串被当 text-shadow 值 → 崩 | 字符串 "false" → undefined(关闭辉光) | 0.3.7 |
| 15 | fontPath 单文件按 400+700 重复加载 → 假粗体 | 只注册一次(400) | 0.3.7 |
| 16 | logo 本地文件读失败静默丢弃 | `resolveImageSrc` 抛错 | 0.3.7 |
| 17 | Node `Buffer.buffer` 是 `ArrayBuffer\|SharedArrayBuffer` | `as ArrayBuffer` 显式窄化 | P2 |
| 18 | quote 模板用 body 而非必填的 title → 正文丢失 | title 作引言主体 | 0.3.3 |
| 19 | npm 名 media-gen-mcp 被占 | `media-gen-mcp-server` | 0.1.0 |
| 20 | **D2 hex 颜色不加引号** → `#` 被当注释吃掉 | hex 值必须引号: `style.fill: "#f0ff3a"` | 0.3.15 |
| 21 | **D2 整数属性传浮点** → stroke-width/font-size/border-radius/stroke-dash 只接受整数,1.5 报错 | 传整数(2 非 1.5);opacity 例外(接受浮点) | 0.3.16 |

## 5. 代码审查标准(五维度)

每次代码变更必须通过五个维度。前四个是项目自身的工程审查;第五个是**简单架构审查**(引用 `架构想法/02_简单检查清单.md` 的 36 条规则,四刻度+适应度函数+漂移度量)。

| 维度 | 检查点 |
|---|---|
| **① 代码规范** | 命名一致、无死代码/重复、注释准确、无魔法数字、与既有风格一致 |
| **② 数据逻辑** | 字段路由(无静默丢弃)、缓存正确性、类型安全、边界(空串/坏路径/undefined/null)、off-by-one |
| **③ 业务逻辑** | 行为符合意图、优雅降级、错误消息清晰、必填字段不被忽略、功能组合不冲突 |
| **④ 端到端接通** | handler↔render 参数完整接通(无 param 漏传)、schema↔实现一致、关注点分离、无全局状态泄漏 |
| **⑤ 简单架构审查** | 按 `架构想法/02_简单检查清单.md` 检查架构简单性(下方详述) |

**方法**:5 维度并行审查 + 对抗验证(只留验证为真实的问题),修复至零。

### 5.1 简单架构审查(第五维度)

> **完整规则**:36 条,见 `架构想法/02_简单检查清单.md`(四刻度 + 抽象成本 + 适应度函数 + 漂移度量 + review 三问)。
> **审查原则**:简单 = 抽象层面的简单(不是"读起来顺");simple ≠ easy(只有结构证据才算违例);阈值是尺子不是法律(命中≠有罪)。

**本项目起步最小集(6 条,优先执行)**:

| 规则 ID | 规则 | 级别 | 本项目适用场景 |
|---|---|---|---|
| **R-FF-01** | 分层/依赖方向:工具层不直接访问 provider 内部;DiagramEngine 不依赖 MediaProvider | 🔴 Fail | 新增 provider/engine 时检查依赖方向 |
| **R-FF-02** | 循环依赖 = 0 | 🔴 Fail | card.ts ↔ diagram/ ↔ providers/ 无环 |
| **R-DEP-03** | 穿堂式方法(pass-through)= 0 | 🔴 Fail | 工具 handler 不应只原样转发(0.3.7 审查已清) |
| **R-CHG-01** | 变更放大率:单次需求改动触及 ≥5 文件 = 告警 | 🟡 Warn | 趋势监控,非 per-PR 闸门 |
| **R-CI-01** | 术语一致:同概念一名(fetch/get/retrieve 不混用;provider/engine/tool 层次术语统一) | 🟡 Warn | 命名表维护 |
| **review 三问** | (1)是否引入"第二套做同一件事的方式"?(2)抽象暴露 what 还是 how?(3)共享函数是否在按 caller 分流? | 🔵 Review | PR 模板自答 |

**防偏差红线**(AI 审查员绝对不做):
- 🚫 把 easy 当 simple("难读"≠"不简单")。
- 🚫 把阈值当法律(命中默认 🟡;只有 R-FF-01/02/04 是 🔴)。
- 🚫 发明规则(清单外发现→"清单外观察",不冒充 finding)。
- 🚫 越界改代码(未被授权"修复"时只报告)。
- 🚫 混淆适应度函数(不变量)与目标差距(偏航角)。

## 7. 迭代开发流程(六步)

每次功能迭代严格执行:

1. **功能分析**:深入调研(官方文档),确定执行路径,写分析文档(`doc/parse_X.Y/paresN/`)。
2. **实施**:按确定方向开发,模糊点调查到确定,端到端接通。
3. **代码审查**:五维度审查(§5,含简单架构审查),有问题即修复并复审,直至零问题。
4. **测试**:单元→集成→冒烟→用户(§6),确保与 PRD 对齐。
5. **文档**:更新 README(中/英双语)、排期文档、分析文档。架构/功能变更同步更新**本文件**。
6. **自检**:全部通过方可进入下一阶段。

## 11. 架构决策记录(ADR)

> 2026-08-26 文档整理批补录。每条 ADR 记录:背景 → 裁决 → 备选与状态(否决项不留死角,防止同一提案反复重议)。完整支撑调研见 `.doc-archive-snapshot/` 与 `doc/` 对应文档。

### ADR-1 视觉识别渠道:直连 provider,不封装 zai-mcp(维持现状)

- **背景**:提议封装智谱 zai-mcp-server 为视觉 provider,复用其 Code Plan 配额。
- **裁决**:**不封装**。zai-mcp 后端与已接入的 glm-vision 同源同端点(paas/v4,同一 GLM-4.6V),是同一模型的两条访问通道——"加个稳的视觉 provider"直接扩 glm-vision(key 轮换/重试)成本更低;且默认 Code Plan key 路径合规不成立(唯一合规路径是独立按量计费 key)。tier 建议 8,低于 glm-vision 的 9。
- **状态**:已裁决(2026-07-20,go-with-conditions 但条件路径不选);完整论据见 `doc/zai-mcp封装调研.md`。若未来诉求变为「统一 MCP 协议/复用 zai 专有 prompt 模板」,可重开。

### ADR-2 Google Flow 渠道:内置化(lasso CDP 逆向),链即开关 + 计费确认门

- **背景**:Flow 无官方 API。经 lasso Chrome CDP(9223)页面上下文逆向全部 wire(契约固化于 `doc/flow-api-contract.md` §0-§12),以内置 provider 形态接入(0.13→0.14,工具 flow_status/flow_entity + generate_image/create_video 的 `provider=flow`)。
- **裁决**:**内置化**而非独立 MCP;配套治理硬件——①**渠道优先级硬链(链即开关)**:工具参数点名 > 模态优先级链 fall through > 全局默认;点名 opt-in 渠道(flow)钉定不静默换渠道;链中不配置 = 不启用(不自动路由、不进 fallback)。②**计费确认门**:预估消耗 >0 积分且无 confirmToken → 返回挑战绝不提交,令牌与 key+预估+prompt+输入引用绑定且**单次消费**(B2-high 修复,faaeead)。〔注:原第②件 S000 硬禁用门(`flow.enabled=false`)2026-08-26 删除 —— 与链语义重复的正交维度,渠道启停统一由链控制,显式点名永远合法〕
- **红线**:视频积分绝不自动路由(图/上采样/实体 0 积分;视频 7-100 积分/条必须显式确认)。项目 ID 永久复用 `~/.media-gen-mcp/flow-project.json`(防误提交耗积分教训,2026-08-22)。
- **备选**:等官方 API(无时间表)/ 独立 flow-mcp(治理件吸收后无增量)——均搁置。
- **后续裁决(2026-08-26)**:生图只需参考图能力(images 底图+参考,§7.2 live);**Flow 场景/角色域不用** → flow_entity 工具移除(24→23)。根因:imageReferences PATCH 被服务端拒(六变体 400,契约 §13.1)+ 裸角色引用生图 500 → 工具侧两头断链;调研成果全量存档契约 §13(凭此 30 分钟可恢复)。

### A.1 D2 完整速查表(官方文档:https://d2lang.com)

**语法规则**:
- **map 属性每行一个**(换行分隔)。分号 `;` 也可,但**每行一个最可靠**。**禁止空格分隔多属性** → 报 "unexpected text after double quoted string"。
- **`#` 是注释符 → hex 颜色必须引号包裹**:`style.fill: "#f0ff3a"`(非 `#f0ff3a`,后者被当注释);命名色不用引号 `style.fill: red`;渐变:`style.fill: "linear-gradient(#hex1, #hex2)"`(引号)或 `linear-gradient(red, blue)`(命名色不用)。
- 关键词避免做 key(shape/style/label/direction/near/tooltip/link/icon/width/height/class)。
- **RULE1-3 实证来源**:上述三条语法规则(每行一个属性 / `#` 注释陷阱与 hex 引号 / 整数属性)系 2026-07-21 d2 探针实证——`d2-reserved-word-probe.mjs`(关键词做 key 的四种位置全部报 `must be style.opacity` 类错)、`d2-crossproc-probe.mjs`(跨进程 byte-identical)、`d2-salt-determinism-probe.mjs`(默认 salt 行为),探针脚本与结果 JSON 存档于 `.doc-archive-snapshot/doc_v11/`。

**形状**:rectangle(默认), square, oval, circle, diamond, hexagon, cylinder, page, parallelogram, document, package, step, callout, queue, stored_data, person, cloud;特殊: text, code, class, sql_table, sequence_diagram。

**连接**:`->` `<-` `<->` `--`;标签 `a -> b: label`;链式 `a -> b -> c`;箭头 `source-arrowhead`/`target-arrowhead`(triangle/arrow/diamond/circle)。

**关键属性**:
- `direction: right|left|down|up`(仅顶层)。
- `label`/`shape`/`icon`/`width`/`height`/`tooltip`/`link`。
- `near: top-center`(定位)。

**样式 `style.*`**:fill, stroke, stroke-width, stroke-dash, font-color, font-size, font(mono), border-radius, opacity, shadow, 3d, double-border, bold/italic/underline, fill-pattern, text-transform。

**容器**:嵌套 `{ }`;`_` = 父引用;跨容器 `parent.child`。

**复用**:config `vars: { d2-config: { layout-engine: elk; theme-id: 300 } }`;classes `classes: { X: { style.fill: blue } }` then `obj.class: X`。

**常见错误**:1. 单行空格分隔多属性 → 崩。2. 用 label 而非 key 引用。3. `direction:` 非 shape 级。4. `#` 在 `link:` URL 里变注释。

### A.2 Vega-Lite v5 完整速查表(官方文档:https://vega.github.io/vega-lite/docs/)

**骨架**:`{ data: {...}, mark: "...", encoding: {...} }`

**Mark → 图表类型**:"bar"(柱), "line"(线), "area"(面积), "circle"/"point"(散点), "arc"(饼/环,需 theta), "tick", "text", "boxplot"。

**数据**:`{ values: [{a:"A", b:28}, ...] }` 或 `{ url: "...", format: {type:"csv"} }`。

**编码 channels**:x, y, x2, y2, color, size, shape, opacity, text, tooltip, detail, order, column, row(facets), theta, radius。

**field type**:"quantitative"(数值), "nominal"(分类), "temporal"(日期), "ordinal"(有序)。常量:`{ value: "red" }`。

**关键**:
- **饼图用 `theta`(v5),不是 `angle`**;mark 用 `"arc"` 不是 `"pie"`。环图加 `mark.innerRadius`。
- 聚合:`{ aggregate:"sum", field:"v", type:"quantitative" }`;count 无需 field。
- 堆叠:bar + color 自动堆叠;`"stack": null` 取消。
- 排序:`"sort": "descending"` 或 `"sort": "-y"`。
- 标题:顶层 `"title": "Chart Title"`。

**常见错误**:1. 饼图用 angle 或 mark:"pie"。2. 忘设 type(x/y 默认 nominal)。3. mark 对象缺 type key。

### A.3 Satori CSS 约束(card 引擎内部;官方文档:https://github.com/vercel/satori)

**关键约束(实现侧)**:
- **多子节点 div 必须 `display:"flex"`**。
- **style 值不能含 `undefined`** → 崩。
- **不支持 woff2**(用 woff/ttf)。
- **textShadow + backgroundClip:"text" 不叠加**(shadow 被裁)。
- **flexWrap 默认 "wrap"**(浏览器默认 nowrap——差异!)。
- **无 z-index**(靠 DOM 顺序,后=上)、无 calc、无 3D transform、无 backdrop-filter、无 `<script>`/`<style>`/JS。

**支持的 CSS**:
- 布局:display(flex/contents/none)、position(relative/static/absolute)、flexDirection/Wrap/Grow/Shrink/Basis、alignItems/Content/Self、justifyContent、gap、margin/padding、width/height/min/max-*、overflow(visible/hidden)。
- 盒子:border(shorthand + per-side;solid|dashed)、borderRadius(per-corner + shorthand)、boxShadow、opacity、boxSizing。
- 文字:color、fontFamily/Size/Weight/Style、textAlign、textTransform/Overflow/Decoration/Shadow、lineHeight、letterSpacing、whiteSpace、wordBreak、lineClamp、WebkitTextStroke。
- 背景:backgroundColor、backgroundImage(linear/radial/repeating-gradient, url)、backgroundPosition/Size/Clip/Repeat。
- 特效:filter(含 blur)、2D transform(translate/rotate/scale/skew) + transformOrigin、clipPath、mask*。
- `<img>` 支持 — 必须 width/height。
- backgroundClip:"text" 需组合:backgroundImage + backgroundClip:"text" + WebkitBackgroundClip:"text" + color:"transparent"。
