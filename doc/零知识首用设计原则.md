# 零知识首用设计原则(MCP 工具描述规范)

> 核心原则:**MCP server 不依赖 Claude 的训练数据。工具定义(description + inputSchema)是唯一可靠信息源。**
> 假设 Claude 从未见过本工具(零训练数据),仅凭 description + param descriptions 就能**首次完美使用**。
> **持续维护:每次升级引擎(D2/Vega/Satori/MathJax)或新增功能,必须同步更新本文档 + 对应参数描述。**

## 三层信息(每个工具的 description 必须覆盖)

| 层 | 内容 | 示例 |
|---|---|---|
| **WHEN**(路由) | 意图先行 + 中/日/西/法/德/俄/葡 多语言触发词 + 反 fallback("BUILT IN, 别 shell out / 用 HTML+Chrome / Pillow / matplotlib, prefer this over") | "architecture/flowchart diagrams (架构图/流程图)" |
| **HOW**(语法) | DSL 速查表:语法规则 + 可用选项 + 正确示例 + 常见陷阱 + 官方文档链接 | "D2 map 属性必须每行一个" + shapes 列表 + 示例 |
| **LIMITS**(边界) | 引擎做不到的(JS/动画/woff2/某些 CSS)+ 与相邻工具的划界 | "mermaid 不支持(需浏览器);titleGradient+glow 不叠加" |

## D2 速查表(完整版 — 精简版在 `code` 参数描述里)

**官方文档**:https://d2lang.com

### 语法规则
- **map 属性每行一个**(换行分隔)。分号 `;` 也可,但**每行一个最可靠**。**禁止空格分隔多属性** → 报 "unexpected text after double quoted string"。
- `#` 注释;关键词避免做 key(shape/style/label/direction/near/tooltip/link/icon/width/height/class)。

### 形状
rectangle(默认), square, oval, circle, diamond, hexagon, cylinder, page, parallelogram, document, package, step, callout, queue, stored_data, person, cloud;特殊: text, code, class, sql_table, sequence_diagram。

### 连接
`->` `<-` `<->` `--`;标签 `a -> b: label`;链式 `a -> b -> c`;箭头 `source-arrowhead`/`target-arrowhead`(triangle/arrow/diamond/circle)。

### 关键属性
- `direction: right|left|down|up`(仅顶层)。
- `label`/`shape`/`icon`/`width`/`height`/`tooltip`/`link`。
- `near: top-center`(定位)。

### 样式 `style.*`
fill, stroke, stroke-width, stroke-dash, font-color, font-size, font(mono), border-radius, opacity, shadow, 3d, double-border, bold/italic/underline, fill-pattern, text-transform。

### 容器
嵌套 `{ }`;`_` = 父引用;跨容器 `parent.child`。

### 常见错误
1. 单行空格分隔多属性 → 崩。2. 用 label 而非 key 引用。3. `direction:` 非 shape 级。

## Vega-Lite v5 速查表

**官方文档**:https://vega.github.io/vega-lite/docs/

### 骨架
`{ data: {...}, mark: "...", encoding: {...} }`

### Mark → 图表类型
"bar"(柱), "line"(线), "area"(面积), "circle"/"point"(散点), "arc"(饼/环,需 theta), "tick", "text", "boxplot"。

### 数据
`{ values: [{a:"A", b:28}, ...] }` 或 `{ url: "...", format: {type:"csv"} }`。

### 编码
channels: x/y/color/size/shape/opacity/text/theta/radius。field type: quantitative(数值)/nominal(分类)/temporal(日期)/ordinal(有序)。

### 关键
- **饼图用 `theta`(v5),不是 `angle`**;mark 用 `"arc"` 不是 `"pie"`。
- 聚合:`{ aggregate:"sum", field:"v", type:"quantitative" }`。
- 堆叠:bar + color 自动堆叠;`"stack": null` 取消。

### 常见错误
1. 饼图用 angle 或 mark:"pie"。2. 忘设 type。3. mark 对象缺 type key。

## Satori CSS 约束(card 引擎内部,Claude 用结构化参数不直接写 Satori)

**官方文档**:https://github.com/vercel/satori

### 关键约束(实现侧)
- **多子节点 div 必须 `display:"flex"`**。
- **style 值不能含 `undefined`** → 崩。
- **不支持 woff2**(用 woff/ttf)。
- **textShadow + backgroundClip:"text" 不叠加**(shadow 被裁)。
- **flexWrap 默认 "wrap"**(浏览器默认 nowrap)。
- 无 z-index / calc / 3D transform / backdrop-filter / `<script>` / `<style>` / JS。

### 支持的 CSS
flexbox 全集;textAlign/color/fontSize/fontWeight;backgroundImage(gradient/url)/backgroundClip;textShadow/boxShadow;border/borderRadius;opacity/filter:blur;transform(2D);img(需 width/height)。
