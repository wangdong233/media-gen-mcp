## 〇、先回答:HF 的「分钟」到底是什么?

**是 GPU 计算时长,不是视频时长。** ZeroGPU 配额按你的任务**实际占用 GPU 的秒数**扣(排队不扣,生成才扣)。

换算感(实测锚点:Wan2.2-Lightning 一条 5s 480p ≈ 60-120s GPU):

| 你的配额 | ≈能跑多少 |
|---|---|
| 匿名 2min/天 | ≈1-2 条 Wan2.2/天(且按 IP 记账,共享出口常被别人耗尽) |
| 免费号 5min/天 | ≈3-5 条/天 |
| **PRO 40min/天** | ≈**20-40 条 Wan2.2/天(月 600-1200 条)**;H3(33B 更重,估 2-4min GPU/条)≈**8-20 条/天(月 240-600 条)** ⚠️H3 耗时未实测 |
| PRO 超额 | $1/10min(≈¥0.072/GPU分钟)→ Wan 折 **¥0.07-0.14/条**,比包月单价略贵、比一切商用 API 便宜 |
| 注意 | ①配额按账号、跨 Space 共享,首次使用后 24h 滚动重置 ②部分 Space 用 xlarge GPU 按 **2 倍**扣 ③「40min」是 GPU 时长,**别拿视频秒数换算**——5s 视频吃 1-2min 配额 |
