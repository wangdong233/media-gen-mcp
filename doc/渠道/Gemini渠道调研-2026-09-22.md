## 0. 一页结论

| 决策项 | 结论 |
|---|---|
| **能否接入** | **能,且条件优于 Flow 时代**:登录态已在 lasso profile、网络通路实测通、入口/参数面/产物获取全部实测闭环 |
| **推荐形态** | CDP 页面上下文 UI 驱动(Flow provider 同款家族);StreamGenerate wire 重放仅作备选(无文档嵌套数组,比 Flow 的 tRPC JSON 脆) |
| **计费模型** | **订阅配额制(算力池),非按次积分**:5 小时滚动窗口 + 每周上限;无公开换算表,provider 侧无法精确预估 |
| **免费/付费边界** | 图像(NB2)**免费档也有**;**视频仅付费档**(Plus/Pro/Ultra);NB Pro 重绘仅付费 |
| **用户实测代价** | PRO 账号:1 图 + 1 视频 + 1 文本对话 ≈ **5h 窗口的 24%**(视频消耗显著);周限仅 1% |
| **地区门禁** | **IP 级**(面板显示"新加坡,根据 IP 地址确定");大陆 IP 不可用,出口在可用区即恢复——**比 Flow 的账号地区 L3 死域轻一个量级** |

| **价值判定** | **Gemini 视频 = Omni(Veo 3.1 系)**——Flow 死域后 **Veo 系唯一可达通路**,直接服务 AIGC 剧集工作流"Veo 主力"选型;图像 NB2 为顶级质量免费档补充 |

## 1. 入口与能力(全部实测)

### 1.1 入口形态

对话页输入区「上传和工具」菜单(纯文本 div 节点,非 button——自动化点击须按 textContent 冒泡找祖先):

```
文件 / 云端硬盘 / Google 相册 / Notebooks
制作图片   ← 图像入口(引擎 Nano Banana 2)
制作视频   ← 视频入口(引擎 Omni)
制作音乐
Canvas / Deep Research / 学习辅导 / 个性化智能服务 / Labs
```

- 模式选择器(顶部)只有文本模型:**3.1 Pro / 3.8 Flash / 3.5 Flash-Lite** + 扩展思考——图像/视频是**工具模式**不是模型选项
- 独立视频工作台:`gemini.google.com/videos`("使用 Omni 生成",30+ 模板:微型世界/动漫/像素冒险/80年代MV/美漫/蒙太奇等)
- 独立媒体台:`gemini.google.com/spark`(BETA,Pro/Ultra 档功能)

### 1.2 图像模式实测(✅ 成功)

- prompt "a small red circle on white background" → **16s 出图**
- 模式化输入区:**宽高比控件** + 30+ 风格 chips(80年代复古/素描/电影效果/蒸汽朋克/超现实/Cyborg/柔美人像/油画/光束…)
- 引擎徽章:"使用 Nano Banana 2 生成"
- 产物:DOM 内 `blob:https://gemini.google.com/<uuid>` + 下载/分享/复制图片操作按钮 → **须即时抓取下载**(blob 有时效)
- 图生图:入口存在(上传和工具→文件),未实测

### 1.3 视频模式实测(✅ 成功)

- prompt "a cat slowly walking on a beach, cinematic" → **48s 出片**("I'm generating your video. This could take a few minutes" → "Your video is ready!")
- 控件:**宽高比(横向 16:9)**;引擎徽章 "使用 Omni 生成"
- 产物:`https://contribution.usercontent.google.com/download?c=…` **直链**(带 credentials fetch 可下载;精确分辨率未读出——video 元素处于预加载态,旁证 Omni 系 720p/1080p,接入实施时补)

## 2. wire 协议(抓包实证)

```
POST https://gemini.google.com/_/BardChatUi/data/assistant.lamda.BardFrontendService/StreamGenerate
     ?bl=boq_assistant-bard-web-server_<YYYYMMDD.NN>_p0&f.sid=<会话id>&hl=zh-CN&_reqid=…
body: f.req=[null,"<inner-json-string>",null,"generic"]&at=<XSRF token>

inner(视频模式实例,完整样本 doc/evidence-gemini/gem-fullposts.json):
[
  ["<prompt>",0,null,null,null,null,0,null,null,[null×5,[[null,null,null,1]]]],  ← 消息体(第10项疑为工具/模式标记)
  ["zh-CN"],                    ← 语言
  null,
  "!hYalh…(1584字符)",           ← ★ snapshot(对话状态,含 conversation id)
  "d4200a32dc2d3d8f8f66f81cda8d360d",  ← 对话/RPC id
  …标记位数组… [4,16] …
]
```

- 后台轮询族:`batchexecute?rpcids=PCck7e|VxUbXb|aPya6c|qpEbW|ESY5D|MyzX6c|L5adhe`(均小 payload)
- **经典 Bard BatchExecute 家族**:嵌套数组、无 schema、无文档——比 Flow 的 tRPC+JSON(有形状可推断)逆向难度高一档
- **开源先例成熟**:HanaokaYuzu/Gemini-API(Python,gemini-webapi)已实现图像+视频生成、`__Secure-1PSID/__Secure-1PSIDTS` cookie 认证、**RotateCookies 端点自动轮换 PSIDTS(会话可无限续期)**
- 已知裂缝:该库 2026 年观察"Google enforcement 加强";Issue #318 图像生成流式解析卡 queueing("Stream suspended. No CID found")——印证纯 HTTP 重放路线脆弱
- **结论:接入走 UI 驱动**(点菜单进模式→填 prompt→点发送→轮询 DOM 产物→fetch 下载),对协议改版鲁棒(模式入口稳定,控件选择器易修);StreamGenerate 重放仅在需要并行/提速时再研究 snapshot 语义

## 3. 计费与限制(官方页 + 用户面板双源)

### 3.1 官方规则(support.google.com/gemini/answer/16275805,2026-05-17 起现行)

- **算力制限额**:"factor in the complexity of your prompt, the models and features you use, and the length of your chat"——**无按次计价、无公开换算表**;"Your limit refreshes **every 5 hours** until you reach your **weekly limit**"
- 档位倍率:无计划=标准 / AI Plus=2x / **AI Pro=4x** / AI Ultra=5x 或 20x
- 功能矩阵:

| 功能 | 免费 | Plus | Pro | Ultra |
|---|---|---|---|---|
| 图像生成(Nano Banana 2) | ✅ | ✅ | ✅ | ✅ |
| NB Pro 重绘(Redo) | ❌ | ✅ | ✅ | ✅ |
| **视频生成** | **❌** | ✅ | ✅ | ✅ |
| 音乐生成 | ❌ | ✅ | ✅ | ✅ |
| Gemini Spark | ❌ | ✅ | ✅ | ✅ |
| 上下文窗口 | 32k | 128k | **1M** | 1M |

- "media generation will consume more of your usage";限额可无通知调整;耗尽后付费档降级 Flash-Lite 继续聊
- 配额自读入口:`gemini.google.com` 设置 → 用量限额(可编程——provider 的配额检查面)
- Pro 附送 1000 Flow 积分(Flow 已死域,无价值)

### 3.2 用户账号实测(Usage Limits 面板,evidence 截图)

```
PRO 方案
当前用量:已使用 24% — 重置时间 21:08(5h 滚动窗)
每周限额:已使用 1% — 重置时间 9月29日 10:08
```

- 本调研代价 = 1 图 + 1 视频 + 1 文本对话 ≈ **24% 窗口**——**视频单次消耗显著**(估算单次视频 ≈15-20% 窗口量级,不可精确)
- 周限极宽(1%)→ **5h 窗口是唯一实际约束**;连续批产视频时约每 5h 4-5 条的量级(单账号)

### 3.3 限制与风险清单

| # | 风险 | 等级 | 说明 |
|---|---|---|---|
| 1 | **地区门禁(IP 级)** | 中 | 面板"新加坡,根据 IP 地址确定";AI Pro 可用区无 China(有 HK/TW/MO/SG)。出口漂到不可用区即封、回可用区即恢复——与 Flow L3(账号地区锁死,换 IP 无解)本质不同 |
| 2 | **ToS 自动化灰色** | 中 | Google 条款不允许自动化访问;与 Flow provider 同一风险等级(用户当时已接受该灰色)。2026 年 Google 加强 enforcement,理论上有账号标记风险 |
| 3 | **协议无文档** | 中(可规避) | StreamGenerate 嵌套数组无契约,改版即断——UI 驱动路线将此降为低(入口/控件比 wire 稳) |
| 4 | **无精确计价** | 低 | 确认门只能表述"消耗订阅配额(算力制),视频消耗显著";可联动 Usage 面板读数做低配额警示 |
| 5 | **产物时效** | 低 | 图片 blob 须即时下载;视频直链疑似带过期(未测 TTL,按"即时下载"纪律处理) |
| 6 | 配额窗口耗尽 | 低 | 功能降级/不可用;Usage 面板可预检 |

## 4. 接入蓝图(如实施:provider `gemini`)

```
media-gen-mcp
 └─ provider: gemini(CDP attach lasso chrome-profile @ 9225,复用既有 Google 登录态)
     ├─ 前置自检:登录态(账号徽章)/ IP 地区(设置面板"根据 IP 地址确定")/ Usage 面板配额读数
     ├─ generate_image:「上传和工具」→「制作图片」(NB2)→ 填 prompt →(可选)宽高比/风格 chip
     │    → 发送 → 轮询 DOM(blob img + 下载按钮出现,超时 ~120s)→ 页面上下文 fetch 落盘
     ├─ create_video:「制作视频」(Omni)→ prompt → 宽高比(16:9/…)→ 发送
     │    → 轮询 video 元素/直链(实测 48s,超时预算 ~300s)→ fetch 直链落盘
     ├─ 配额治理:无积分门 → 改「配额警示」(Usage 读数 < 阈值告警;视频消耗大,默认逐条确认)
     └─ 错误映射:登录失效/地区漂移/配额耗尽/生成超时/产物抓取失败 五类结构化码
```

- 工程量评估:**与 Flow provider 同级**(attach/前置/UI 驱动/轮询/下载骨架可大量复用)
- 明确不复制 Flow 的:wire 重放优先(改为 UI 优先)、积分确认门(改为配额警示)
