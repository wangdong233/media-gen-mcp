## 七、方法论与教训汇编(从飞轮 30 轮提炼;每条注出处)

### 7.1 平台模式分类学(轮 7 S7 成型,后续轮补强)
- **A 类=免费锁 UI**(krea/leonardo):API/MCP 与消费侧额度官方隔离——先问「API 与 UI 额度是否隔离」可提前判形态(轮 6)。
- **B 类=免费跟账号+API 同池**(pixai/hfspaces):程序化路径与 UI 同池,构造性必然——B/C 类才值得免费接入。
- **C 类=免费+官方 API 双轨**(siliconflow/cloudflare):还须再问一句「免费侧产物商用授权」(vidu 免费层连个人产出商用都不给,一票否决;轮 8)。

### 7.4 真机验证纪律(S1-S7 七段轮结构)与翻车模式
每轮结构:S1 发现→S2 深挖(lasso 实探+agent 三路,能力边界清单)→S3 三态裁决(GO/SKIP-记册/NO)→S4 实施(channelInfo+能力声明与实现逐项对齐)→S5 双门(机械门全量回归+真机门 XX_IT;无登录态=BLOCKED-on-login 登记)→S6 fresh agent 审查(03 清单)+修复循环→S7 轮末(再发现+自评估+轮报落盘)。撞登录墙→BLOCKED 记录跳队尾,飞轮不停。

高频翻车模式(全部真案):
1. **n² 双重计费**(轮 4 A1 BLOCKER):provider 内 n 循环 × 工具层 runPool 扇出,n=8→64 次调用——provider 必须忽略 n;白盒测试必须含「与工具层契约正交」断言(D1 恒单张)。
2. **静默丢参**(轮 4 B1/轮 20 B-1):丢弃必告警(warn-and-ignore,zhipu 式);能力声明与实现逐项对齐(supportsImageToImage 谎报防线,轮 4)。
3. **`.status` 缺失误重试**(轮 4):抛共享 withRetry 的错误必须带 .status,否则 4xx 被当瞬时错重试 3 次;错误码族 S1xx/S2xx/S3xx/S4xx 全渠道统一。
4. **token 收割面**(轮 27 F-MAJOR):token 附随 Space 返回的任意 URL 外发——恶意 Space 可收割 HF token;收紧为域白名单。安全审查维度新增「凭据外发面」。
5. **量能坍塌**(轮 21 pixai):官方「×4 批次价÷4」口径误导,API 单张不享折扣,10,000 积分/日实为 2-4 张/日——文档价与 API 价必须分离验证。
