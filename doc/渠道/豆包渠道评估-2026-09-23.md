## 1. 豆包网页版 NO 的四重理由(能力路×技术路交叉定谳)

1. **免费额度撑不起工作流**:视频每日 10 额度 ≈ **50 秒**(仅 5/10s 片;Seedance 2.5 仅专业版);生图额度未公开且 2026-04 起持续收紧(token 动态换算,官方从不给固定张数)
2. **水印是法定硬伤**:所有生图强制水印 + 《AI 生成合成内容标识办法》法定显式/元数据双标识,**用户协议 6.4 明文禁止删除/篡改**;先例项目 doubao2api 实证"无法绕过"——对 AIGC 成片用途直接否决
3. **非商业许可**:协议 2.10 条授予的是"**个人的、可撤销的、非商业的**"使用权;付费协议 6.5 反营利(违者取消权益不退款)——商用管线合规风险
4. **反自动化条款 + 字节行为风控**:协议 5.1.1 明禁"未经授权的插件/外挂/第三方工具";a_bogus/msToken 设备指纹 + 验证码挑战(错误码 710022004)+ 多账号/批量行为封号案例——灰色度显著高于 gemini 先例(技术路评分 3.5/5,工程上可行[两个活跃开源先例]但收益倒挂)

**收益倒挂是核心**:同款模型走火山 API 只要 0.30 元/张且无全部四重问题——网页逆向的价值仅剩"免费 50 秒视频/天",不值得。

## 2. 技术面档案(若未来仍要 UI 驱动,留档)

- 先例:**doubao2api**(243★,in-page fetch 桥接 SSE,`/samantha/chat/completion` 生图/视频端点,风控码处理)+ **doubao-web-to-api**(CDP+持久 profile,与 gemini 渠道架构完全同款);LLM-Red-Team 原版已消失(清理风险信号)
- wire:字节自有 HTTP RPC + SSE;签名(a_bogus/msToken)在真实浏览器内发请求可绕(lasso/CDP 天然免疫此层)
- 登录:扫码一次,sessionid cookie 长期复用;风控纪律=验证码触发即停人工接管、单账号不轮询
