## 1. 平台画像(四路交叉)

- **定位**:AI 设计 Agent 平台(非模型聚合站)——MCoT 引擎自动在 30+ 模型间路由 + ChatCanvas 画布 + Touch Edit;宣称 30M 用户
- **主体**:Resonate International INC(Delaware);**实为 LiblibAI(哩布哩布)海外产品**(阿里云美区 OSS/changelog 存 liblib 域/tldraw fork 实证);创始系前字节剪映全球商业化负责人
- **健康度**:2026-06 近 $3 亿 B+ 轮(腾讯/顺为领投,投后 >$20 亿)、2026-08 筹备港股 IPO(目标 $30 亿)——**跑路风险低**;"模型中间商无自研"的商业模式质疑存在(观察者网)
- **口碑**:2025 上半年媒体一面倒;2026 起付费用户投诉成簇(积分消耗快/扣费退款难/客服失联,Trustpilot+黑猫+虎嗅互证);英语社区(Reddit)实质零讨论

## 2. 接入形态(对抗复核裁决)

**唯一通路:Agent OpenAPI**(官方仓库 lovartai/lovart-skill,MIT,131★,持续更新):

```
网关     https://lgw.lovart.ai/v1/openapi/*(Kong;实测无认证 400 = 真实在线)
认证     AK/SK(网页端 头像菜单→AK/SK 管理;每账号 ≤3 把 key)
         HMAC-SHA256 over "METHOD\nPATH\nTIMESTAMP" + 五签名头
核心流   POST /chat(提交)→ GET /chat/status|/chat/result(轮询)
         POST /chat/confirm(高成本确认:视频/premium 图 → pending_confirmation
         带 estimated_cost —— 与项目两段式计费确认门天然同构!)
模型控制 --prefer-models(软偏好)/--include-tools(强引导,非白名单)
限流     写 60/min·600/h;读 300/min·3000/h;429+Retry-After
并发     单 thread 同时 1 个生成任务;多 thread 可并发
参考实现 官方 agent_skill.py ≈900 行纯 Python 标准库零依赖(TS 移植面小)
```

**关键差异 vs 既有渠道**:这是**编排型 API**——发 prompt,Agent 自主选模型出活;没有 pixverse 式的逐参数直调。media-gen-mcp 侧的参数(aspect/seed/quality/numFrames)只能 prompt 软表达,工具层须按"丢弃必告警"纪律逐项 warning。

## 5. 条款合规(条款路全文 + 复核)

- **产出权属**:✅ Output 归用户(含权利转让条款),商用允许,无收入分成——四路中最干净的一条
- **反向授权**:⚠️ 用户内容授 Lovart 永久可再许可许可("improve and develop the Services")——训练用途未明示但条款留空间,**无 opt-out**;上传敏感底图需知悉
- **自动化**:ToS §4.2 blanket 反自动化条款("any automated means…for any purpose")——但**官方同时发布 Agent OpenAPI 明示供脚本/助手调用**(README 点名 Claude Code/Cursor),API 限流即官方边界;风控 FAQ 条款限定于 Relax 免费队列语境。**裁决:走官方 API+fast 模式 = 平台明示服务形态;网页自动化/relax 自动化 = 灰色到正面冲突,不接**
- **数据**:存美国;内容可能按设置展示给其他用户(注册后须核对默认隐私设置)

## 6. 风险登记与工具层对策(用户要求"外部调用不受限制影响")

| 风险 | 工具层对策(内聚进 provider,调用方无感) |
|---|---|
| Account Farming 误伤(重度高频画像) | ①写限流内敛至官方 60/min 的一半(默认 30/min,可配);②单 thread 串行;③连续生成间隔 ≥2s;④用量统计入 warnings(日累计提醒) |
| Relax 模式条款红线 | provider **硬禁** unlimited 模式(不透传 set-mode;配置了也拒绝并说明) |
| 高成本误扣(pending_confirmation) | 映射到项目两段式确认门:estimated_cost → confirmToken → 复调确认(语义天然对齐,零新机制) |
| 任务 done 但内含失败工具调用仍扣积分(官方已知坑) | result 解析 failures[] 数组,部分失败 → 项目 partial 一等承载 + warnings |
| 费率不透明 | 确认门第一段展示 estimated_cost;costCatalog 登记实测价(ledger 自学习,复用 pixverse 三态) |
| 封号不退款 | 订阅决策交用户;provider 启动警示年费/退款条款(一次性 banner) |

## 7. 实施方案(飞轮复用,若用户裁决 GO)

**前置(用户人工,一次性)**:①注册账号(建议直接 Pro 年付或先 Starter 小试——注意用过即不退);②头像菜单→AK/SK 管理签发 key(实测免费账号是否可签,决定试水成本);③key 配入 `~/.media-gen-mcp/config.json`(providers.lovart.accessKey/secretKey)。

**Provider 落点(src/providers/lovart.ts,第 6 渠道)**:

```
HTTP provider(agent_skill.py TS 移植,HMAC 五头签名 ≈100 行)
├─ generateImage:prefer-models 软引导 + prompt 参数软表达 + data:URI 落盘管线
│    参数纪律:aspect/seed/size/quality 不被 API 消费 → 逐项 warning(丢弃必告警)
├─ createVideo:/chat 提交 → pending_confirmation → 两段确认门(estimated_cost)
│    → confirm → status 轮询(429 Retry-After 遵守)→ result 取件
├─ getVideo:status/result 轮询(伪 handle 同 gemini 模式)
├─ costCatalog:三态(实测 ledger > 官方 3 模型价 > unknown)
├─ 用量自律层:30/min 内敛限速 + relax 硬禁 + failures[] partial 承载
└─ requiresOptIn=true(计费渠道);disabledProviders 可禁(0.22.0 通用机制零改动)
```

**轮次**(复用 gemini 飞轮纪律):R0 用户注册+AK/SK 实测(阻塞项:免费层上限/真实费率/首尾帧能力三未知在此轮实测)→ R1 签名+骨架(白盒)→ R2 图像全链 → R3 视频全链(含确认门)→ R4 治理 → R5 fresh 审查 → R6 文档+发版。测试纪律同 gemini:LOVART_IT 双门(默认永不真连)、零消耗白盒、magic 真值校验。

**不接**(明确边界):3D/音频(超模态)、relax 模式、网页 UI 驱动(条款灰色且有 API 正路)。

## 8. 待用户裁决项

1. **GO/NO-GO**:技术全绿;商业上 Pro 年付 $540(首年)的模型面增量(MJ/GPT Image 2.5/Kling 3.0/Veo 3.1 API)是否值得——对照:pixverse $96/年已有 Seedance 系,gemini 已有 NB2/Veo 系,lovart 的独家实质是 **MJ + GPT Image 2.5 + 最大聚合广度**
2. **试水路径**:Starter $19/月小试(可验 AK/SK+费率+首尾帧三未知)vs 直接 Pro 年付(单价减半+Relax 权益——但 Relax 禁自动化,权益对本用途无价值,**建议不为此升级**)
3. **风控自律参数**:默认 30/min 内敛 + 日用量警示线(建议 500 积分/日)是否接受
