## 一、AI 生成(文生图 / 文生视频,四渠道)

### 1.1 generate_image — 文生图 / 图生图

| 项 | 说明 |
|---|---|
| 功能 | 文生图;图生图(底图+参考图) |
| 渠道 | **agnes**(默认,免费)/ **zhipu**(免费)/ **flow**(Google Flow,账号地区门禁暂不可用)/ **pixverse**(订阅池,生图/视频一律扣订阅积分——CLI 无 Relax 免费池,qwen-image 实扣 5/10cr;两段确认门+成本台账)/ **gemini**(网页渠道 CDP UI 驱动,模型 nano-banana-2;Google AI 订阅算力配额制,无按次积分;产物 JPEG 经 data:URI 落盘;requiresOptIn)|
| 关键参数 | prompt(必)、model、n(1-8)、size、aspect(16:9/9:16/1:1/3:4/4:3,flow)、seed(flow,可复现)、images(底图+参考图;flow ≤10 张/agnes 图生图)、provider |
| 产物 | 落盘 `./output`(服务启动目录=启动任务的项目;config `outDir` 可全局改):`name` 指定文件名(Flow 原生不存名→下载时本地重命名;同名已存在自动 -2/-3 避让绝不覆盖),`outDir` 指定目录;返回 file↔mediaId↔seed↔prompt 完整映射;data:URI 自动剔除防上下文爆 |

#### flow 渠道生图模式详表(代码实态:src/providers/flow.ts)

**模型 key(全部 0 积分)**:

| model key | 产品名 | 定位 |
|---|---|---|
| `NARWHAL`(默认)| Nano Banana 2 | 默认文生图 |
| `GEM_PIX_2` | Nano Banana Pro | 高质量,参考图最多 10 张 |
| `HARBOR_SEAL` | Nano Banana 2 Lite | 轻量档 |
| `GEM_PIX_2_UPSAMPLE_2K` | — | **2K 放大特殊模式**(独立端点 /v1/flow/upsampleImage) |

**参数行为**:

| 参数 | flow 行为 |
|---|---|
| aspect | 一等参数精确映射:16:9→LANDSCAPE / 9:16→PORTRAIT / 1:1→SQUARE / 3:4→PORTRAIT_THREE_FOUR / 4:3→LANDSCAPE_FOUR_THREE;非法 S301 |
| seed | 直进 wire;outputs[].seed 回填实际值(可复现);缺省随机 1-999999 |
| size | 不吃精确像素,映射最近比例(1920x1080→16:9 等);精确比例传 aspect |
| images | images[0]=底图(BASE_IMAGE,**比例强制随底图**,显式 aspect 告警忽略);images[1..]=参考图(REFERENCE);合计 ≤10 否则 S301;上传 0 积分 |
| n | 客户端扇出 n 次单图提交;部分成功返回 warnings |
| 放大模式 | model=GEM_PIX_2_UPSAMPLE_2K + images[0](mediaId 或 URI 自动上传);prompt 忽略(告警);video mediaId 拒(S301);0 积分 |
| 产物 | outputs[] = {url(data:URI), mediaId, seed};mediaId 可 flow_status 复查/复下载/删除/分享 |

flow 不支持:精确像素 size / watermark / 服务端批量 n(其它渠道能力)。

## 二、视觉理解(图/PDF → 数据,四档)

### 2.1 extract_text — 文字识别(OCR)
验证码/发票/扫描件/聊天记录。参数:segmentation / outputFormat(text+blocks) / **layout**(多栏阅读序还原,natural=GapTree 段落)/ **ignoreAreas**(水印/红章/页眉剔除)/ digitOnly。

### 2.2 extract_table — 表格识别
图 → HTML/Markdown/JSON/LaTeX(发票/报表/论文表格)。

### 2.3 analyze_chart — 图表反推数据
柱/线/饼/散点图 → 结构化数据序列。

### 2.4 describe_image — 看图问答(VQA)
自然语言描述 / 手写 / 公式 / 复杂场景理解。

### 2.5 extract_pdf / get_pdf — PDF 提取(异步)
数字版秒出(文字层);扫描件逐页 OCR;页码范围(`3`/`1-10`/`odd`/`last`)/ 忽略区 / 多栏 / 分页或合并;长文档后台跑。

**四档识别引擎**(默认头 tesseract;tesseract 不支持的 task 自动路由 / 失败 fallback 按 tier 降序):tesseract(进程内,零配置,默认头兼最后兜底)→ paddle(10,自托管,表格/图表)→ glm-vision(9,智谱云,中文 SOTA+VQA,免费)→ vlm(8,vLLM,手写/增强)。

## 五、渠道治理(配置统一控制)

### 5.1 渠道路由(0.22.0:优先级链已废弃,选择权交调用方)

**设计依据(2026-09-23 用户裁决)**:渠道选择是「调用时点」的业务决策(免费试稿 → 付费定稿),静态优先级链(装机时点)表达不了任务内变化;选择知识内置于各工具 `provider` 参数的选型对比面,由有业务上下文的调用方自主点名。

| 路由形态 | 行为 |
|---|---|
| **缺省(不传 provider)** | 免费池:agnes → zhipu 自动容灾互备(60s 熔断;唯一可配置项 = `defaultImageProvider` / `defaultVideoProvider` legacy 默认头) |
| **点名 gemini / pixverse(opt-in)** | 点名即用且钉死:失败直抛结构化错,绝不静默换渠道;费用安全由配额警示(gemini)与两段确认门(pixverse)兜底 |
| **点名免费渠道** | 失败仍按免费池回落(带告警,零回归) |
| **禁用渠道(默认 flow)** | 路由层结构性拒绝:零网络零 CDP,错误附死域背景 + 替代渠道 + 解禁指引 |

- 🔴 旧 `imageProviderPriority` / `videoProviderPriority` / `MEDIA_*_PROVIDER_PRIORITY` **已废弃**:读到即警告并忽略(平滑迁移);`getProviderPriority` 恒 undefined
- 模型归属自动路由保留(model → 唯一拥有者);**禁用渠道不参与归属**(死渠道模型 → "未知模型")

### 5.2 disabledProviders(渠道禁用表,配置化非硬代码)

```jsonc
// ~/.media-gen-mcp/config.json
"disabledProviders": ["flow"]   // 默认值:flow = L3 账号地区门禁死域(2026-09-10 起)
                                 // 显式写 [] = 解禁全部;可列任意渠道名(如禁 pixverse)
// env 等价:MEDIA_DISABLED_PROVIDERS="flow,pixverse"(config 数组优先)
```

- 单点拦截:`getProvider` 路由层(显式点名/模型归属/自省全路径共用此闸;`list_models` 对禁用渠道返回 `{disabled: true}` 条目而非抛错)
- 集成测试:flow 套件恒 skip(禁用语义优先于 FLOW_IT 门;解禁后恢复三门控制)
- fallback 候选过滤:禁用渠道永不承接

### 5.3 fallback(免费池容灾)

同模态免费渠道间自动切换(agnes↔zhipu;isFallbackWorthy 5xx/网络/429 + 环境前置);**opt-in 渠道与禁用渠道永不进隐式 fallback**(0.22.0 起无链豁免通道 —— 语义比链时代更严:隐式路径永远免费)。
