## 一、AI 生成(文生图 / 文生视频,三渠道)

### 1.1 generate_image — 文生图 / 图生图

| 项 | 说明 |
|---|---|
| 功能 | 文生图;图生图(底图+参考图) |
| 渠道 | **agnes**(默认,免费)/ **zhipu**(免费)/ **flow**(Google Flow,生图 **0 积分**)|
| 关键参数 | prompt(必)、model、n(1-8)、size、aspect(16:9/9:16/1:1/3:4/4:3,flow)、seed(flow,可复现)、images(底图+参考图;flow ≤10 张/agnes 图生图)、provider |
| 产物 | 落盘 `./output`(服务启动目录=启动任务的项目;config `outDir` 可全局改):`name` 指定文件名(Flow 原生不存名→下载时本地重命名;同名已存在自动 -2/-3 避让绝不覆盖),`outDir` 指定目录;返回 file↔mediaId↔seed↔prompt 完整映射;data:URI 自动剔除防上下文爆 |

#### flow 渠道生图模式详表(代码实态:src/providers/flow.ts)

**模型 key(全部 0 积分)**:

| model key | 产品名 | 定位 |
|---|---|---|
| `NARWHAL`(默认)| Nano Banana 2 | 默认文生图 |
| `GEM_PIX_2` | Nano Banana Pro | 高质量,参考图最多 10 张 |
| `HARBOR_SEAL` | Nano Banana 2 Lite | 轻量档 |
| `GEM_PIX_2_UPSAMPLE_2K` | — | **2K 放大特殊模式**(独立端点 /v1/flow/upsampleImage) |

**参数行为**:

| 参数 | flow 行为 |
|---|---|
| aspect | 一等参数精确映射:16:9→LANDSCAPE / 9:16→PORTRAIT / 1:1→SQUARE / 3:4→PORTRAIT_THREE_FOUR / 4:3→LANDSCAPE_FOUR_THREE;非法 S301 |
| seed | 直进 wire;outputs[].seed 回填实际值(可复现);缺省随机 1-999999 |
| size | 不吃精确像素,映射最近比例(1920x1080→16:9 等);精确比例传 aspect |
| images | images[0]=底图(BASE_IMAGE,**比例强制随底图**,显式 aspect 告警忽略);images[1..]=参考图(REFERENCE);合计 ≤10 否则 S301;上传 0 积分 |
| n | 客户端扇出 n 次单图提交;部分成功返回 warnings |
| 放大模式 | model=GEM_PIX_2_UPSAMPLE_2K + images[0](mediaId 或 URI 自动上传);prompt 忽略(告警);video mediaId 拒(S301);0 积分 |
| 产物 | outputs[] = {url(data:URI), mediaId, seed};mediaId 可 flow_status 复查/复下载/删除/分享 |

flow 不支持:精确像素 size / watermark / 服务端批量 n(其它渠道能力)。

### 1.2 create_video — 文生视频(七种模式)

| 模式 | 参数 | 说明 |
|---|---|---|
| t2v 文生视频 | prompt + model | 纯文本(flow 侧 wire 仅形状验证,provider 路径未 live 提交)|
| i2v 图生视频 | prompt + image | 起始图(0 积分上传)|
| r2v 参考图生视频 | prompt + images(abra 最多 7 张 / veo 3 张)+ 可选 audioMediaIds | 角色锚点一致性;audioMediaIds 挂 30 预设语音做声音参考(实验期,flow_status voices 取 id)|
| 首尾帧插值 | keyframes(恰 2 张)| interpolation/_fl key |
| 延长 | videoMediaId | extension key |
| 编辑 V2V | videoMediaId + prompt | abra_edit 20 积分;wire 探针定型,live 未验证(响应带警示)|
| 超分 1080p | videoMediaId | **0 积分**;所有生成 key 固定 720P,更高分辨率仅超分 |

- 渠道:agnes/zhipu(免费,异步 handle)/ flow(积分,见 §五 治理)
- 时长:4/6/8/10s(durationSeconds 自动吸附;veo 家族无 10s —— 仅 4/6/8s 或 key 自带时长);比例 16:9/9:16
- flow 积分表(tier 盲估算):abra 7-20 / veo_lite 10 / veo_fast 20 / veo_quality 100 / upsampler **0**;🔴 per-tier 真值(契约 §14.4):lite ADVANCED=5、fast 的 ultra/4s/6s 变体仅 ADVANCED=10、low_priority 仅 ADVANCED=0、plain fast 在 ADVANCED 不可用 —— 当前档不可用的 key 提交前 S303 拒绝并附各档价目(确认门与提交点双拦)
- x2-x4 = 重复调用 N 次(每次独立计费;seed 每次随机,显式传 seed 则 N 次复用同一 seed)

### 1.3 get_video — 视频取件

轮询异步任务(handle→completed)→ 下载落盘(`name`/`outDir` 同 generate_image,防覆盖避让同);flow 渠道兼容(取 mediaId 状态;kind 门禁防图当视频;返回 mediaId/seed/model/**prompt** 回读,产物与输入一一对应)。

## 二、视觉理解(图/PDF → 数据,四档)

### 2.1 extract_text — 文字识别(OCR)
验证码/发票/扫描件/聊天记录。参数:segmentation / outputFormat(text+blocks) / **layout**(多栏阅读序还原,natural=GapTree 段落)/ **ignoreAreas**(水印/红章/页眉剔除)/ digitOnly。

### 2.2 extract_table — 表格识别
图 → HTML/Markdown/JSON/LaTeX(发票/报表/论文表格)。

### 2.3 analyze_chart — 图表反推数据
柱/线/饼/散点图 → 结构化数据序列。

### 2.4 describe_image — 看图问答(VQA)
自然语言描述 / 手写 / 公式 / 复杂场景理解。

### 2.5 extract_pdf / get_pdf — PDF 提取(异步)
数字版秒出(文字层);扫描件逐页 OCR;页码范围(`3`/`1-10`/`odd`/`last`)/ 忽略区 / 多栏 / 分页或合并;长文档后台跑。

**四档识别引擎**(默认头 tesseract;tesseract 不支持的 task 自动路由 / 失败 fallback 按 tier 降序):tesseract(进程内,零配置,默认头兼最后兜底)→ paddle(10,自托管,表格/图表)→ glm-vision(9,智谱云,中文 SOTA+VQA,免费)→ vlm(8,vLLM,手写/增强)。

## 五、渠道治理(配置统一控制)

### 5.1 渠道优先级(硬链,handler 级确定性路由;**链即开关**)
```jsonc
// ~/.media-gen-mcp/config.json
"imageProviderPriority": ["flow", "agnes", "zhipu"],   // 生图 flow 优先(0 积分)
"videoProviderPriority": ["agnes", "zhipu"]              // 视频默认免费渠道
```
用户只说"生图"→按链走,失败自动回落(60s 熔断);不配置=默认行为(agnes/zhipu 链,flow 显式)。**渠道启停的唯一控制源就是链**:不配置 = 不启用(不自动路由、不进 fallback),列出 = 启用;显式 `provider="flow"` 点名永远合法(环境不可用返回结构化 S1xx 前置错)。无单独 enabled 开关(2026-08-26 删除 S000 硬门,与链语义重复)。

### 5.2 flow 渠道治理件
- **计费确认门**:视频提交前两段式 confirmToken(动态积分预估/单次消费/TTL 600s/全参数绑定);`flow.videoConfirm=false` 可关
- **防 stall 截止**:`flow.toolDeadlineMs`(默认 110s,单次调用 ≤120s 红线);超时转 S410,底层不取消
- 前置:本机 Chrome 9223(lasso)+ labs.google 登录;失败给结构化指引(S100/S101/S102)

### 5.3 fallback
同模态渠道间自动切换(isFallbackWorthy:5xx/网络/429);flow 不作隐式 fallback 源(显式钉死)。
